# 火山视窗 PC 开发技能（volcano-windows-dev）

本技能基于《火山视窗全栈开发技能书》V2.6（59 轮校验）与 4 份官方知识库沉淀而成，适用于火山视窗 PC（Windows 桌面）平台 wsv 文本格式源程序开发。

## 何时使用

- 编写 / 修改 / 审查 `.wsv` 源程序（完整程序或代码片段）；
- 查询或核实火山类库的类名、方法名、属性名、事件名、常量名及其真实签名；
- 排查编译报错、语法错误、事件不触发、模块引用失败、运行期异常；
- 需要把 C++/易语言思路翻译为符合 wsv 标准的火山代码。

## 核心红线（不可违反）

1. **禁止编造 API**：输出中出现的每一个类名、方法名、属性名、事件名、常量名、命令关键字，必须能在知识库接口文件（`*_j.txt`）或权威文档中找到原文证据。查不到即不存在，不得"推测合理"补写或借用其他语言的 API 名。
2. **代码必须完全符合 wsv 格式标准**：声明行、成员定义、属性表、语句行 `<>` 前缀、逻辑值无引号、注释标记（`#`/`//` 各司其职，见下"自查三要素"）等一律按标准书写（细则见 [01-wsv语法标准速查.md](references/01-wsv语法标准速查.md)）。
3. **证据优先级**：`火山wsv文件格式标准.md` ＞ `火山视窗平台封装语法手册.md` ＞ 模块接口 `*_j.txt` ＞ 官方 demo 源码。冲突时以高优先级为准。

## 知识库位置（本项目内）

| 知识库 | 路径 | 说明 |
|--------|------|------|
| 权威规范 | `火山视窗AI辅助文件/` | 封装语法手册 / 模块信息 / 项目文件格式技术规范 |
| wsv 格式标准 | `火山wsv文件格式标准.md` | 语法唯一权威 |
| 模块接口 | `视窗模块源码wsv格式AI知识库/*_j.txt` | 可读 JSON：classes/methods/properties/events/constants |
| 模块源码 | `视窗模块源码wsv格式AI知识库/*_p.txt` | wsv 源码，多为双重编码（解码法见 [09-知识库使用指引.md](references/09-知识库使用指引.md)） |
| 官方示例 | `视窗wsv源码demoAI知识库/` | 254 对 demo（`*_j.txt` 接口 + `*_p.txt` 源码） |

> 接口文件名约定：`sys_<分组目录>_<模块名>_j.txt`，如 `sys_mfc_ui_base_w_mfc_base_control_j.txt`。文件头（前几行）含"需要引用模块"显示名与 `"package name"`。

## 标准开发流程

1. **查接口**：确定功能归属模块 → Grep 该模块 `*_j.txt` 检索类名/方法名 → 核对真实签名（参数名、参数顺序、类型、`@默认值`、返回类型、静态与否）。
2. **写代码**：按 wsv 标准书写（声明行 → 包 → 类 → 方法 → 参数 → 语句），代码示例必须可编译。
3. **自查三要素**：
   - 事件接收方法名 = `事件对象类名_事件名`（如 `按钮_被单击`、`时钟_周期事件`），并声明 `<接收事件>`；
   - 逻辑值写 `真`/`假` 不带引号；文本值带双引号；
   - 语句注释用 `//`（仅方法体内）；文档/类注释行以 `#` 开头（`# [属性表] 注释内容`）；成员注释用 `注释 = "..."` 属性；字符字面量用 `' '`。
4. **对照官方 demo**：涉及某模块时，优先参考 demo 知识库中同名 demo 的真实用法（源码 `_p.txt` 双重编码需先解码）。

## 关键规则速查

### 最小可编译 wsv 骨架

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

包 火山.用户.示例

类 启动类 <公开 基础类 = 窗口程序类>
{
    变量 主窗口对象 <类型 = 主窗口>

    方法 启动方法 <公开 类型 = 整数>
    {
        主窗口对象.创建主窗口 ()
        返回 0
    }
}
```

### 启动类基础类（仅 4 个，无"控制台程序类"）

| 程序形态 | 启动类基础类 |
|---------|-------------|
| 控制台 / 无窗口 | `程序类` |
| 界面（窗口） | `窗口程序类` |
| 动态链接库 | `动态库程序类` |
| （三者根基） | `程序基础类` |

### 事件接收方法三要素（缺一即不触发）

```火山代码
方法 按钮_被单击 <接收事件 类型 = 整数>   // ① 名 = 类名_事件名 ② 声明接收事件
参数 来源对象 <类型 = 按钮>               // ③ 第1参数 = 事件对象类名
参数 标记值 <类型 = 整数>                 // 第2参数固定整数标记值（自动挂接为0）
{
    返回 0
}
```

- 非静态成员变量默认自动挂接事件（`@自动挂接事件` 属性可关闭）；动态创建的组件需 `挂接事件 (对象, 标记值)` 手动挂接。
- 多个同类控件共用一个接收方法，用 `如果 (来源对象 == 成员变量)` 区分来源。

### 高频易错点

- 文件首非空行必须是 `<火山程序 类型 = "通常" 版本 = 1 />`，文件须 UTF-8 编码；
- 视窗平台换行用 `\r\n`；文本中双引号转义 `\"`、反斜杠 `\\`；
- 对象变量默认自动创建实例；`参考 = 真` 仅作引用，须先赋值为已有实例；
- 常量初始值只能是立即数；属性表值非名称/数值格式时：除"值"以外的系统属性用双引号（如 `"123a"`），"值"系统属性及非系统属性必须用 `@` 引导的转义字符串（如 `@"123a"`）；
- 语句行以 `<`、标准所列保留词（包/package、类/class、方法/method、参数/param、常量/const、变量/var）开头或为单个 `{`/`}` 时，须加空属性表 `<>` 前缀（如 `const int i` 须写为 `<> const int i`）；
- 流程语句的 `{` 与 `}` 必须**独占一行**（不能单行书写 `如果 (x) { ... }`）；`如果` 必须带子语句体；`否则` 必须紧跟"如果"语句体的 `}` 之后，且省略判断条件后不能再后续跟随其它"否则"。
