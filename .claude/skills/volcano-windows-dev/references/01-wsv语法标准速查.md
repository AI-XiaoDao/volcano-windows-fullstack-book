# 01 wsv 语法标准速查

> 依据源：《火山wsv文件格式标准》（权威标准文档）与《火山视窗全栈开发技能书》V2.6 第1~5章。
> 两源矛盾处以 V2.6 技能书（较新、修正后）为准，并标（V2.6修正）。本速查只压缩源材料原文，不新增内容。

## 1. 文档格式术语

| 术语 | 定义 |
|------|------|
| wsv | 火山平台源程序的 UTF-8 编码文本格式，后缀为 `.wsv` |
| 完整程序数据 | 保存一个完整的火山程序数据 |
| 剪切程序数据 | 保存复制到剪贴板中的火山程序数据片段 |
| 规则描述格式 A | 名称以 `xxx/xxx` 格式提供时，分别为其中文和英文名称 |
| 规则描述格式 B | 中括号括住的名称表示该部分可以被省略 |
| 单名称 | 以英文字母/下划线/汉字开头，后跟字母/下划线/数字/汉字 |
| 全名称 | 以句点组合多个单名称，如 `火山.程序` |
| 标识符名称 | 多个单词 + 版本号，如 `cplus.win32.console.1` |
| 属性表 | 以尖括号括住、由名称-值对组成的成员附加信息定义 |
| 文档声明行 | 首非空行必须为的文档格式和版本定义行 |

- **注意**：火山中的名称对英文字母的大小写敏感，`abc` 与 `ABC` 不是同一名称。
- 工程由 `.vprj`/`.vsln`/`.vgrp` 纯文本文件组织（`.vprj` 为 UTF-8 编码；`.vsln`/`.vgrp` 同为 UTF-8 纯文本，见技能书 15.3 节）。

## 2. 文档声明行

无论是完整程序数据还是剪切程序数据，**首非空行必须为文档格式和版本定义行**：

```
<火山程序/volprg 类型/type = 类型名称 版本/version = 版本号 />
```

| 属性 | 取值 | 说明 |
|------|------|------|
| 类型/type | `通常` / `normal` | 当前火山程序文档的格式类型文本 |
| 版本/version | `1` | 目前最新版本号 |

> **易错点**：首行必须严格为声明行，否则解析器无法识别文件格式。

## 3. 火山程序整体结构

```
文档声明行
包定义（唯一，必须位于首部）
  ├── 文档注释行 / 文档嵌入行
  └── 类定义
        ├── 类嵌入行 / 类注释行
        ├── 类成员常量
        ├── 类成员变量
        └── 类成员方法
              ├── 方法参数
              ├── 方法局部常量
              ├── 方法局部变量
              ├── 语句注释行
              ├── 语句嵌入行
              └── 火山语句行
```

参考代码：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

包 火山.视窗.ELK引擎

类 ELK引擎类 <公开 注释 = "★ 本类由\"飞翔的企鹅\"封装." @视窗.外部头文件 = "lib\\elk_vol.h">
{
    #
    常量 成员常量1 <类型 = 整数 值 = 123>
    变量 成员变量1 <公开 类型 = 整数 值 = 123>

    方法 执行 <公开 类型 = 文本型 注释 = "执行指定的JavaScript代码并返回其执行结果." @嵌入式方法 = "">
    参数 内容 <类型 = 文本型 注释 = "提供所欲执行的JS代码内容">
    {
        常量 局部常量 <类型 = 整数 值 = 123>
        变量 局部变量1 <类型 = 整数 值 = 111>
    }
}
```

**包定义**：包名必须为全名称。关键规则：
1. 包定义成员始终位于源文件首部，且只能存在一个；
2. 多个程序文件可具有相同的包名，此时其内容被视为处于同一个包中；
3. 包定义支持 `@外部包` 属性（允许多设置项），用于指定在本源文件内优先查询的外部包名列表，解决类名冲突。

## 4. 成员定义格式总表

**成员名称**格式要求：成员名称如果不为有效的单/全名称文本，就必须使用以双引号括住的转义字符串格式（如 `方法 "// 方法1"`）。

所有以花括号括住的代码块如果其中内容为空，则整个花括号代码块可以全部被省略。

| 类型 | 语法格式 | 所支持系统属性 | 注释 |
|------|---------|--------------|------|
| 包 | `包/package 包名称 [属性表]` | 注释折叠2 | 必须为第一个成员定义而且只能存在一个 |
| 类 | `类/class 类名称 [属性表] { 类定义体}` | 公开基础类注释折叠折叠2 | 必须位于文档顶层 |
| 方法 | `方法/method 方法名称 [属性表] [参数表]... { 子语句体}` | 公开静态定义事件接收事件属性读属性写类型注释返回值注释折叠折叠2 | 1. 参数表为所有参数的定义行集合，如果存在必须顺序排列在方法定义行的下面。2. 必须位于类定义体中，剪切程序数据中可以位于文档顶层 |
| 参数 | `参数/param 参数名称 [属性表]` | 类型注释折叠(仅限首参数)折叠2 | 必须跟随在方法定义行后面，剪切程序数据中可以位于文档顶层 |
| 常量 | `常量/const 常量名称 [属性表]` | 公开(仅限类成员常量)类型值注释折叠(仅限多个连续常量中的首常量)折叠2 | 必须位于类定义体(成员常量)或方法子语句体(局部常量)中，剪切程序数据中可以位于文档顶层 |
| 变量 | `变量/var 变量名称 [属性表]` | 公开(仅限类成员变量)（V2.6修正：源标准误作"仅限类成员常量"，V2.6技能书2.4节明确公开变量可在类外部访问、局部变量没有此属性）静态参考类型值注释折叠(仅限多个连续变量中的首变量)折叠2 | 必须位于类定义体(成员变量)或方法子语句体(局部变量)中，剪切程序数据中可以位于文档顶层 |
| 文档或类注释/嵌入行 | `# [属性表] 注释/嵌入行内容` |  | 必须位于文档顶层或类定义体中。注意：如果注释/嵌入行内容以 '<' 字符开头，则无论该行是否具有属性，都必须在内容前方添加一个空属性表。如：`# <abc` 就必须使用 `# <> <abc` 表达 |
| 语句行 | `[属性表] 语句行内容 { 子语句体}` | 折叠 | 必须位于方法或另一语句的子语句体中，剪切程序数据中可以位于文档顶层（注意见 §7） |

## 5. 属性表定义格式

```
<属性名称 [ = 属性值] ......>
```

属性表内容以一个或多个以空白字符分隔的名称和值对组成，其中可以使用换行符在多行中进行描述。

**属性名称格式要求**：属性名称如果不为有效的单/全名称文本（可以以 `@` 字符引导），或者为与已有系统属性（见 §6 系统属性表）的中/英文名称相同的非系统属性，必须使用以双引号括住的转义字符串格式。

**属性值格式要求**：

- **A.** 如果当前属性为除开"值"以外的系统属性：
  1. 单/全名称文本；
  2. 以下数据类型的有效值：逻辑值（如 真 / 假）、数值（如 123, 1.23, 0x123, -123, 1.23e3）；
  3. 以双引号括住的转义字符串。当属性值无法以前面几项描述时，必须以此格式描述，系统将取用该字符串转义后的字面文本作为属性值。譬如属性值 `123a` 就必须以 `"123a"` 描述；
  4. 如果没有提供属性值，则该属性的值默认为逻辑值真。
- **B.** 如果当前属性为"值"系统属性或非系统属性：
  1. 单/全名称文本；
  2. 以下数据类型的有效值：数组（如 `{ 1, 2, 3 }`）、逻辑值（如 真 / 假）、文本（如 `"abc"`）、字符（如 `'a'`）、数值（如 123, 1.23, 0x123, -123, 1.23e3）；
  3. 以 `@` 字符开头的单/全名称文本（火山程序中用作引用本地名称值）；
  4. 以 `@` 字符开头的以双引号括住的转义字符串。当属性值无法以前面几项描述时，必须以此格式描述。譬如属性值 `123a` 就必须以 `@"123a"` 描述；
  5. 如果没有提供属性值，则该属性的值默认为无。

## 7. 语句行与空属性表 <> 前缀规则

语句行格式：`[属性表] 语句行内容 { 子语句体}`，必须位于方法或另一语句的子语句体中（剪切程序数据中可以位于文档顶层）。

**注意**：在以下几种情况下，无论该行是否具有属性，都必须在内容前方添加一个空属性表 `<>`：
1. 语句行内容以 `<` 字符开头；
2. 语句行内容以以下单词（以空白字符和后方内容隔开）开头：**包, package, 类, class, 方法, method, 参数, param, 常量, const, 变量, var**；
3. 语句行内容为单个的 `{` 或 `}` 字符。

如：`const int i` 语句行必须以 `<> const int i` 表达，`<123` 语句行必须以 `<> <123` 表达。

```火山代码
<> 包 ...
<> 类 ...
<> 变量 ...
<> 常量 ...
<> 参数 ...
<> 方法 ...
<> {
我的函数 ()
<> }
<> <...
<> #...
```

## 8. 注释与嵌入行

**注释定义方式**：
- **A.** 任何定义型成员其名称以连续两个 `/` 字符引导，说明其处于被注释状态，编译时被忽略（如 `方法 "// 方法1"`）；
- **B.** 类外部的程序行称为**文档注释行**；类内部但在类方法外部的程序行称为**类注释行**；
- **C.** 类方法内部使用连续两个 `/` 字符引导一直到行尾的**语句注释文本**（如 `参数1.信息框 ("abc") // 注释信息`）。

文档/类注释行定义格式：`# [属性表] 注释内容`，必须位于文档顶层或类定义体中。

**嵌入行**：程序行行首以一个独立的 `@` 字符开头（与后内容必须用空白字符隔开），编译时直接发送到目的平台编译器，由用户保证其语法正确性：

```火山代码
# @ 嵌入行
@ 嵌入语句行
```

**重要注意**：如果注释/嵌入行内容以 `<` 字符开头，则无论该行是否具有属性，都必须在内容前方添加一个空属性表：

```wsv
# <> <abc
```

**文档中批量嵌入行**：使用 `@begin` 和 `@end` 关键字行括住一批程序行（**不支持在类/方法中使用**）：

```火山代码
# @begin
# <global>
# void my_global_func ()
# {
# }
# </global>
# @end
```

**嵌入行内容分区**（指定其编译后所处位置）：

| 分区 | 语法 | 说明 |
|------|------|------|
| 头文件内容分区 | `<include>` ... `</include>` | 内容位于编译后的头文件(.h)中，否则位于cpp源文件中 |
| 全局命名空间分区 | `<global>` ... `</global>` | 内容位于全局命名空间中，否则位于当前包局部命名空间 |

```火山代码
# <include>
# #ifdef _VOL_MFC
# #if(defined(_CONSOLE) || defined(@an<_VOL_CONSOLE_EXE>))
# #elif(defined(_USRDLL) || defined(@an<_VOL_DLL>))
# #endif
# </include>
```

## 9. 立即数格式

| 类别 | 格式 |
|------|------|
| 十进制整数/小数 | `123`、`1.23`、`1.23e3`（科学计数法） |
| 十六进制整数 | `0x12AC3F` |
| 字符整数值 | `'A'`（单引号，如 `值 = ' ' 类型 = 字符`） |
| 逻辑型 | 真 / 假 |
| 字符串 | 双引号括住，支持转义符 |
| 数组 | 花括号括住，如 `{ 1, 2, 3 }` |

- **强制指定数值类型**：使用强制类型转换操作符 `(长整数)1`。
- 如果某整数超出整数的最大有效范围，将自动被设定为长整数类型，如 `0x123456789A` 自动为长整数。
- 立即数名称关键字：`真(true)`、`假(false)`、`空对象(null)`；**空对象（null）**可匹配所有非常量类的类数据类型以及文本型。

## 10. 字符串转义符

| 转义符 | 解释 | 转义符 | 解释 |
|--------|------|--------|------|
| \b | 退格符 | \r | 回车符 |
| \f | 换页符 | \n | 换行符 |
| \t | 水平制表符 | \\ | 反斜杠 |
| \' | 单引号 | \" | 双引号 |
| \u | 后跟1-4个十六进制字符（Unicode代码值） | \x | 后跟1-2个十六进制字符（代码字节值） |
| 八进制 | \后跟1-3个八进制字符 | - | - |

> **视窗平台重要注意**：在火山视窗平台里，如果欲达到换行效果，需要插入 **`\r\n`**（回车+换行）两个字符。

## 11. 数组数据类型与数组立即数

数组数据类型为基本/类数据类型后面跟随一个或多个数组维定义组成：

```火山代码
单维文本数组数据类型：文本 []
多维整数数组数据类型：整数 [] []
定义指定成员数目的整数数组变量：整数 [3], 整数 [3][3]
```

**数组立即数**：使用花括号括住，多维数组可嵌套 `{ { 1, 2 }, { 3, 4 } }`。多维数组各维成员数目必须相等，`{ { 1, 2 }, { 3 } }` 是**不允许**的（只能在提供数组常量/变量初始值时使用）。

## 12. 基本数据类型速查（类型属性取值）

| 中文名称 | 输入字 | C++对应 | 占用字节 | 有效值范围 |
|---------|--------|---------|---------|-----------|
| 字节 | `sbyte` | signed char | 1 | -128 ~ 127 |
| 短整数 | `short` | short | 2 | -32768 ~ 32767 |
| 字符 | `wchar` | wchar_t | 2 | 0 ~ 65535 |
| 整数 | `int` | int | 4 | -2147483648 ~ 2147483647 |
| 变整数 | `vint` | intptr_t | 4/8 | 等于目标CPU位数（常用于指针值） |
| 长整数 | `long` | long long | 8 | -9.22E18 ~ 9.22E18 |
| 单精度小数 | `float` | float | 4 | -3.40E38 ~ 3.40E38 |
| 小数 | `double` | double | 8 | -1.7E308 ~ 1.7E308 |
| 逻辑型 | `bool` | bool | 1 | 真 / 假 |
| 文本型 | `string` | CVolString | - | Unicode 文本 |

> 容量排序：字节 < 短整数 < 字符 < 整数 < 长整数 < 小数；计算表达式数据类型取表达式中具有最大容量的数值数据类型。

## 13. 变量与常量定义

```火山代码
变量 变量1 <公开 静态 参考 类型 = 整数>
```

**变量基本属性**：

| 属性 | 说明 |
|------|------|
| 类型 | 提供变量的数据类型 |
| 静态 | 静态变量在类载入后即保持始终存在。注意：静态成员变量不支持自动挂接事件，需手动"挂接事件"；外部以"类名.变量名"引用 |
| 参考 | 参考属性为假时自动创建实例对象；为真时仅用作指向其它已有实例的引用 |
| 公开 | 公开变量可在类外部访问；局部变量没有此属性 |
| 初始值 | 可提供立即数或常量；参考变量可提供"空对象" |

**默认初始值规则**：数值型为 0，逻辑型为假，文本型为空文本，参考变量为"空对象"。

**变量初始值示例**（含数组初始值）：

```火山代码
变量 变量2 <值 = { "a", { "b", "c" }, "d" } 属性1 = ' ' 属性2 = "abc\t" 类型 = "文本型 []">
变量 变量3 <值 = ' ' 类型 = 字符>
```

```火山代码
常量 常量1 <公开 类型 = 整数 值 = 123>
```

- 类的成员常量在外部应通过 `类名.常量名` 方式引用；
- 初始值只能提供**立即数**，不能提供其它常量；
- 可以使用 `@` 字符引导的文本来指定常量的本地初始化值文本（用户自行保证有效性，火山编译器不检查）：

```火山代码
常量 相邻像素 <公开 值 = @"@CxImage::InterpolationMethod::IM_NEAREST_NEIGHBOUR" 注释 = "为位置相邻的像素.">
```

## 14. 方法定义与参数

```火山代码
方法 方法 <公开 静态 类型 = 整数 注释 = "这是方法注释" 返回值注释 = "这是返回值注释">
参数 参数1 <类型 = 整数 注释 = "这是参数1注释">
参数 参数2 <类型 = 整数 注释 = "这是参数2注释">
{
    返回 (参数1 + 参数2)
}
```

**方法基本属性**：

| 属性 | 说明 |
|------|------|
| 返回值类型（类型） | 方法执行完毕后返回的数据类型 |
| 静态 | 静态方法通过"类名.方法名"引用；内部只能访问所在类或其基础类的成员常量或静态成员变量 |
| 公开 | 公开方法可在类外部访问 |
| 参数表 | 所有参数的定义行，顺序排列在方法定义行下方 |

**方法类别（类别属性）**：

| 类别 | 说明 | 格式要求 |
|------|------|---------|
| 通常 | 普通方法 | 无特殊要求 |
| 属性读 | 属性可在语句中被读取 | 非静态：无参数+必须有非数组返回值 |
| 属性写 | 属性可在语句中被赋值 | 非静态：无返回值+只能定义1个非数组参数 |
| 定义事件 | 定义本类对象将发送的事件 | 方法体必须为空；返回值必须为整数；不能为静态 |
| 接收事件 | 接收成员对象发送的事件 | 返回整数、非静态；方法名格式为"事件所属类名_欲接收事件名" |

**接收事件方法格式要求**：
- 第1个参数数据类型为欲接收其事件的事件源对象所属类；
- 第2个参数数据类型为整数，接收"挂接事件"调用所提供的标记值；
- 其余参数数目及类型必须与欲接收事件的定义方法一致。

**特殊方法**（类对象生命周期）：

```火山代码
类 测试类
{
    方法 类_初始化
    {

    }
}
```

```火山代码
类 测试类
{
    方法 类_清理
    {

    }
}
```

- **类_初始化**：类对象被创建时自动调用，不携带参数且不返回值；**类_清理**：类对象被销毁时自动调用。

**参数的属性详解**：

| 属性 | 说明 |
|------|------|
| @默认值 | 为参数提供调用方未提供对应数据时的默认值，须与参数数据类型匹配；数组/类/文本型参数可设为"空对象" |
| @常量参数 | 设置为真说明参数内容在方法内部不可被修改（仅非嵌入式方法） |
| @匹配类型 | 参数增强通配模式（仅嵌入式方法参数，此时不能设置数据类型），取值见下表 |
| @需求类型 | 1. 可写入变量：调用方需提供可修改内容的变量；2. 立即数或常量（仅嵌入式方法）；3. 数据类型：调用方需提供数据类型名称（仅嵌入式方法） |
| @可扩展 | 仅嵌入式方法最后一个参数，调用时可被扩展 |
| @返回值类型 | 仅嵌入式方法参数，指定方法的返回值数据类型为调用时提供的本参数数据的当前实际数据类型 |

**@匹配类型取值**：

| 值 | 匹配 |
|----|------|
| 通用整数型 | 所有非数组整数类型 |
| 通用数值型 | 所有非数组数值型类型 |
| 通用非文本基本型 | 非数组非文本基本类型 |
| 通用基本型 | 所有非数组基本数据类型 |
| 本地类 | 所有非数组本地类 |
| 通用类 | 所有非数组类定义数据类型 |
| 通用型 | 所有非数组数据类型 |
| 通用型数组等 | 对应数据类型的数组变体 |
| 所有类型 | 所有数组和非数组数据类型 |
| 等于前参数值类型 | 须与前方参数值数据类型一致 |
| 匹配前参数值类型 | 前方参数值数据类型必须能够正常转换到当前参数值数据类型，不能用在第一个参数上（不支持同时定义参数默认值） |
| 等于前参数值模板类型 | 前方参数值的数据类型必须为模板实现类，本参数值数据类型须与其模板类型1一致（不支持同时定义参数默认值） |

## 15. 类定义语法与类属性

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

类 测试类 <公开 基础类 = 窗口>
{
    #
}
```

**基本属性**：
- **基础类**：指定本类的基础类名称，可为空文本（表示无基础类）。定义非空基础类后自动继承其所有内容。名称为"启动类"的类用作特定定义用户程序的启动类。
- **公开**：公开类可以在所处包外部被访问，非公开类只能在包内被访问。
- 继承类访问基础类中的成员不需要其为公开状态。

**类的特殊属性**：

| 属性 | 要点 |
|------|------|
| @常量类 | 指定类是否为常量类及其对应的基本数据类型。特点：类中只允许定义数据类型为该类的常量成员（类型为空时自动默认为所处常量类）；基础类只能是常量类（对应基本数据类型必须一致）；数据类型为常量类的局部变量访问前必须首先明确赋值；常量类不能与对应基本数据类型匹配，但可强制转换。对应数据类型选择项：字节、短整数、字符、整数、变整数、长整数、单精度小数、小数、逻辑型、文本型、文本到ID |
| @类用途 | 1. 通常（默认）；2. 禁止创建对象：不允许定义常量/变量（参考变量/数组变量除外）的数据类型；3. 定义嵌入参数类型：不允许定义除嵌入式方法参数之外成员的数据类型（"假"别名类）；4. 访问静态成员：只能用作访问类中的静态/常量成员，实现"命名空间"作用 |
| @别名 | 表明该类为别名类，直接封装所指定的目标语言本地类。特点：只允许定义常量/变量/静态方法成员；成员变量必须指定@输出名（假变量）；可为其它非别名类的基础类 |
| @别名类型 | 1. 火山类（默认）：实现了火山对象接口要求的本地类（C++从CVolObject类继承）；2. 本地类：未实现火山对象接口的复合数据类型（如C++ class）；3. 本地结构：未实现火山对象接口且没有自行初始化构造能力（如C++ struct）；4. 本地整数基本类型：对应整数基本类型（如无符号整数），须提供"有效值范围"属性；5. 本地值类型：必定不以参考或指针方式定义和传递数据；6. 本地参考类型：对应参考或指针型数据类型（不支持C++参考，支持指针） |
| @全局类 | 全局类中的所有静态公开方法在外部访问时都可以省略其类名指定（嵌入行语句中除外），此类方法被称为全局方法 |
| @本地类 | 编译时不附加任何火山对象类的额外信息。特点：不能是别名类或常量类，不能具有基础类；类中不能定义通常火山程序类的非参考成员变量，不能定义事件/虚拟方法 |
| @模板基础类 / @模板实现类 | 模板基础类只能用作模板实现类或其它模板基础类的基础类，只有在此类中才能使用模板数据类型（模板类型1~8）；模板实现类基础类必须为模板基础类，本属性值顺序提供所有模板数据类型的实际替换数据类型 |
| @默认基础类 | 当其它类（不包括常量类）没有指定基础类时，使用该类作为默认基础类。要求：整个应用程序中只允许一个类被定义为默认基础类；该类不允许定义有基础类、不允许为常量类；必须确保其为所有外部本地类的实际基础类，且定义有无参数构造方法 |
| @禁止创建对象 | 不允许用作定义常量/变量（参考变量/数组变量除外）的数据类型 |
| @禁止静态 | 是否允许定义该类及其所有继承类的静态或静态参考变量 |
| @禁止继承 | 是否不允许本类作为其它类的基础类 |
| @虚拟方法 | 指定方法为虚拟方法，可选"可覆盖/不可覆盖" |
| @自动挂接事件 | 是否自动将该类或类对象支持的所有事件挂接到本类上（默认真） |
| @属性变量 | 指定非静态类成员变量是否为其所处类的属性型成员 |
| @输出名 | 指定编译后的输出名称 |
| @废弃 | 标记该类或方法已被废弃（警告/错误） |
| @强制输出 | 指定类/方法将被强制编译输出 |
| @强制依赖 | 强制指定一个或多个类为本类/方法的依赖类 |

## 16. 嵌入行替换符与宏

| 替换符 | 格式 | 解释 |
|--------|------|------|
| @<成员名称> | `@<对象变量1.成员1>` | 引用指定成员/参数名称。注意：所有参数仅允许在嵌入行中引用一次（需求类型为"数据类型"的参数除外） |
| @n<成员名称> | `@n<对象变量1.成员1>` | 仅加入最后的成员名称；不受静态成员访问格式和访问权限限制 |
| @dt<类型名称> | `@dt<整数>, @dt<模板类型1>` | 引用指定数据类型名称。不支持数组；别名类使用所封装本地类名 |
| @fdt<类型名称> | - | 与@dt基本相同，类数据类型始终使用全名称 |
| @pkg<包名称> | `@pkg<火山.用户.程序>` | 引用指定包名称 |
| @an<约定名称> | `@an<CVolString>` | 引用全局/项目插件约定名称 |
| @sn<特定名称> | `@sn<current_class>` | 引用特定名称（见下表） |
| @pdt<参数名称> | - | 引用指定参数的实际调用值数据类型 |
| @pvpt<参数名称> | - | 引用参数所提供实际调用立即数/常量值的字面文本 |
| @pdt_ch<参数名称> | - | 引用参数实际调用值数据类型的标识字符 |
| @pdt_list<参数名称> | - | 引用从指定参数开始到参数表尾部所有参数值的数据类型列表 |
| @def_macro / @m<> | - | 定义/使用嵌入行宏 |
| @pad<参数名称> | - | 数组参数维数文本（非数组为"0"） |

**选项字符**（可结合 @dt/@fdt/@pkg/@an/@n/直接@<> 使用）：
- `n`：使用纯粹名称（去除尾部星号及首部P/P_/LP/LP_）；
- `e`：未找到所指定名称成员时不报告编译错误（整个嵌入行被删除）；
- `b`：找到替换为逻辑真文本，未找到替换为假文本。

**@sn<特定名称> 支持列表**：

| 名称 | 解释 |
|------|------|
| current_class | 嵌入行当前调用位置所处类名 |
| current_package | 嵌入行当前调用位置所处包名 |
| current_method | 嵌入行当前调用位置所处方法名 |
| base_class | 嵌入行当前调用位置所处类的基础类名 |
| current_class_def | 嵌入行定义位置所处类名 |
| current_package_def | 嵌入行定义位置所处包名 |
| base_class_def | 嵌入行定义位置所处类的基础类名 |
| startup_method | 程序启动方法名（必须位于启动类中） |
| startup_class | 程序启动类名 |
| startup_package | 程序启动类所处包的包名 |
| this | 只能在非静态嵌入式方法的嵌入行中使用，替换为调用该嵌入式方法时提供的调用对象 |
| quot / apos | 双引号字符 / 单引号字符 |
| lt / gt / nbsp | 左尖括号 / 右尖括号 / 空格 |
| pm_types | 全部参数实际调用值数据类型的标识字符串 |
| rand_name0~9 | 随机生成的程序内唯一性名称（同一嵌入式方法体内相同名称文本一致） |
| current_statment | 当前语句位置字符串 |
| current_source_file/line/package/class/method | 当前语句所处源文件/行号/包/类/方法 |

**宏的定义与使用**：

```火山代码
@def_macro TEST wutao
@def_macro TEST(param1) param1
@def_macro TEST(param1) #param1      // 替换为 "abc"（加双引号）
@def_macro TEST(param1,param2) wutao_##param1##param2##_var
```

```火山代码
@m<TEST>
@m<TEST> ("wutao", "volcano")
```

> **宏参数替换规则**：
> - 参数前方1个`#`：替换为字符串格式（自动加双引号）；
> - 参数前/后方2个`#`：自动与前后内容连接起来；
> - 使用宏时实际参数数目超出定义宏参数数目时，多余参数统一视为最后一个宏参数的替换内容；
> - 多行宏内容：当前行尾部使用 `\` 标记下一嵌入行也属于本宏内容。

## 17. @嵌入式方法

指定方法为嵌入式方法，方法体内的嵌入行将与调用参数组合起来替换调用语句本身。

**属性表属性**：

| 属性 | 类型 | 默认 | 说明 |
|------|------|------|------|
| name | 文本型 | - | 本嵌入式方法的标记名称，仅在所处类中使用 |
| has_body | 逻辑型 | 假 | 调用语句是否携带子语句体 |
| has_loop_body | 逻辑型 | 假 | 是否携带循环体类型子语句体（支持"到循环尾/跳出循环"） |
| body_header / body_tail | 文本型 | - | 子语句体首部/尾部加入的本地代码行（c/c++默认`{`/`}`） |
| prev / next | 文本型 | - | 调用语句前/后必须存在的嵌入式方法标记名列表 |
| parent / child | 文本型 | - | 调用语句必须位于/只能包含指定嵌入式方法的子语句体 |
| lineal_parent | 逻辑型 | 假 | 是否必须直接位于父语句子语句体中 |
| req_obj_param_pointer | 逻辑型 | 假 | 文本型/对象型参数转换为对象地址指针 |
| req_str_param_text_pointer | 逻辑型 | 假 | 文本型参数转换为文本数据指针(const TCHAR*) |
| no_end_sem | 逻辑型 | 假 | 调用语句尾部是否不自动加号分号 |
| req_cpp_bool | 逻辑型 | 假 | 逻辑型参数使用C++ boolean类型 |

**嵌入式方法注意事项**：
1. 自动禁止流程检查；
2. 设置有 has_body/has_loop_body/prev/next 时不能定义返回值；
3. 类_初始化/类_清理/属性写/事件定义/接收/虚拟方法均不能设置为嵌入式方法；
4. 嵌入式方法内只能存在嵌入行语句；
5. 嵌入行内访问嵌入式方法参数以外成员时，必须明确指定类名前缀且该类必须为公开类；
6. 对方法的调用将直接替换调用语句本身，编译器自动在替换文本两侧加左右小括号。

## 20. 易错点与注意汇总

1. 首非空行必须为文档声明行 `<火山程序 类型 = "通常" 版本 = 1 />`，否则解析器无法识别文件格式；
2. 成员名称不为有效单/全名称文本时必须用双引号转义字符串格式（如 `方法 "// 方法1"`）；
3. 名称对英文字母大小写敏感；
4. 属性值无法以名称/立即数描述时必须用双引号（系统属性）或 `@"..."`（"值"/非系统属性）转义字符串格式；
5. 系统属性未提供属性值默认逻辑值真；"值"/非系统属性未提供属性值默认为无；
6. 注释/嵌入行内容以 `<` 开头必须加空属性表：`# <> <abc`；
7. 语句行内容以 `<`、保留单词（包/类/方法/参数/常量/变量及英文对应词）、单个 `{` 或 `}` 开头时必须加空属性表 `<>`；
8. 嵌入行 `@` 必须与后内容用空白字符隔开；
9. 批量嵌入行 `@begin`/`@end` 不支持在类/方法中使用；
10. 视窗平台换行需插入 `\r\n` 两个字符；
11. 多维数组立即数各维成员数目必须相等；数组立即数只能在提供数组常量/变量初始值时使用；
12. 常量初始值只能提供立即数，不能提供其它常量；
13. 静态成员变量不支持自动挂接事件，需手动"挂接事件"；
14. 接收事件方法名必须为"事件所属类名_欲接收事件名"格式，参数须满足 §14 格式要求；
15. 方法定义有非空返回值时必须提供返回值；否则必须省略返回参数；
16. @嵌入式方法有 6 条使用限制（见 §17）；
17. 嵌入行中所有参数仅允许引用一次（需求类型为"数据类型"的参数除外）；
18. 属性表内多个"注释"/"返回值注释"属性将分行组合在一起。
