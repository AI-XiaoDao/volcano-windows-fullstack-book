## 一、10 种基本数据类型（2.1 / 附录A·三）

| 中文名称 | 输入字 | C++对应 | 占用字节 | 有效值范围 |
|---------|--------|---------|---------|-----------|
| 字节 | `sbyte` | signed char | 1 | -128 ~ 127 |
| 短整数 | `short` | short | 2 | -32768 ~ 32767 |
| 字符 | `wchar` | wchar_t | 2 | 0 ~ 65535 |
| 整数 | `int` | int | 4 | -2147483648 ~ 2147483647 |
| 变整数 | `vint` | intptr_t | 4/8 | 等于目标CPU位数（常用于指针值） |
| 长整数 | `long` | long long | 8 | -9.22E18 ~ 9.22E18 |
| 单精度小数 | `float` | float | 4 | -3.40E38 ~ 3.40E38 |
| 小数 | `double` | double | 8 | -1.7E308 ~ 1.7E308 |
| 逻辑型 | `bool` | bool | 1 | 真 / 假 |
| 文本型 | `string` | CVolString | - | Unicode 文本 |

- **容量排序**：字节 < 短整数 < 字符 < 整数 < 长整数 < 小数
- **计算表达式数据类型**：取表达式中具有最大容量的数值数据类型。
- **注意**：基本数据类型为上述 10 种；`字节集` 是类数据类型（字节集类，属"视窗基本类"模块，包名 火山.基本，见 6.4/附录A·十三）。

### 数组数据类型（2.2）

数组数据类型为基本/类数据类型后面跟随一个或多个数组维定义组成：

```火山代码
单维文本数组数据类型：文本 []
多维整数数组数据类型：整数 [] []
定义指定成员数目的整数数组变量：整数 [3], 整数 [3][3]
```

**数组立即数**：使用花括号括住，多维数组可嵌套 `{ { 1, 2 }, { 3, 4 } }`。多维数组各维成员数目必须相等，`{ { 1, 2 }, { 3 } }` 是**不允许**的（只能在提供数组常量/变量初始值时使用）。

## 二、立即数与转义符（2.3）

| 类别 | 格式 |
|------|------|
| 十进制整数/小数 | `123`、`1.23`、`1.23e3`（科学计数法） |
| 十六进制整数 | `0x12AC3F` |
| 字符整数值 | `'A'`（单引号） |
| 逻辑型 | 真 / 假 |
| 字符串 | 双引号括住，支持转义符 |
| 数组 | 花括号括住 |

**字符串转义符**：

| 转义符 | 解释 | 转义符 | 解释 |
|--------|------|--------|------|
| \b | 退格符 | \r | 回车符 |
| \f | 换页符 | \n | 换行符 |
| \t | 水平制表符 | \\ | 反斜杠 |
| \' | 单引号 | \" | 双引号 |
| \u | 后跟1-4个十六进制字符（Unicode代码值） | \x | 后跟1-2个十六进制字符（代码字节值） |
| 八进制 | \后跟1-3个八进制字符 | - | - |

> **视窗平台重要注意**：在火山视窗平台里，如果欲达到换行效果，需要插入 **`\r\n`**（回车+换行）两个字符。

**强制指定数值类型**：使用强制类型转换操作符 `(长整数)1`。如果某整数超出整数的最大有效范围，将自动被设定为长整数类型，如 `0x123456789A` 自动为长整数。

## 三、变量与常量定义（2.4 / 2.5）

```火山代码
变量 变量1 <公开 静态 参考 类型 = 整数>
```

**变量基本属性**：

| 属性 | 说明 |
|------|------|
| 类型 | 提供变量的数据类型 |
| 静态 | 静态变量在类载入后即保持始终存在。注意：静态成员变量不支持自动挂接事件，需手动"挂接事件"；外部以"类名.变量名"引用 |
| 参考 | 参考属性为假时自动创建实例对象；为真时仅用作指向其它已有实例的引用 |
| 公开 | 公开变量可在类外部访问；局部变量没有此属性 |
| 初始值 | 可提供立即数或常量；参考变量可提供"空对象" |

**默认初始值规则**：数值型为 0，逻辑型为假，文本型为空文本，参考变量为"空对象"。

```火山代码
变量 变量2 <值 = { "a", { "b", "c" }, "d" } 属性1 = ' ' 属性2 = "abc\t" 类型 = "文本型 []">
变量 变量3 <值 = ' ' 类型 = 字符>
```

**常量定义**：

```火山代码
常量 常量1 <公开 类型 = 整数 值 = 123>
```

- 类的成员常量在外部应通过 `类名.常量名` 方式引用；
- 初始值只能提供**立即数**，不能提供其它常量；
- 可以使用 `@` 字符引导的文本来指定常量的本地初始化值文本（用户自行保证有效性，火山编译器不检查）：

```火山代码
常量 相邻像素 <公开 值 = @"@CxImage::InterpolationMethod::IM_NEAREST_NEIGHBOUR" 注释 = "为位置相邻的像素.">
```

| 5 | `<=` `>=` `<` `>` `属于(instanceof)` | 比较/属于 |

| 7 | `&&`（且） | 并且 |

### 关键操作符详解（2.6.2）

**强制类型转换**：`(欲强行转换到的数据类型)欲转换类型的数据`
- "空对象"可转换到任何非常量类的类数据类型或文本型；
- 数值数据类型之间可强行转换；
- 常量类可强制转换到对应基本数据类型；
- 类只能强制转换到其直接/间接基础类或继承类。

**属于（instanceof）**：返回左侧对象是否为右侧类或其直接/间接继承类的实例对象。

**等于 / 不等于**：
- 数组对象唯一能比较的是"空对象"；
- 文本比较实际内容（区分大小写），也可与"空对象"比较；
- 类对象比较的是**对象地址**是否相同。要比较内容，使用系统类库 `对象内容是否相同` 全局方法；**字节集类是特例**，对象间比较会比较实际数据内容。

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 结果 <类型 = 整数>
变量 逻辑结果 <类型 = 逻辑型>

结果 = 10 + 20 * 3        // 结果为 70（乘除优先于加减）
逻辑结果 = (结果 > 50) 且 (结果 < 100)   // 结果为真
```

### 如果 / 否则（3.1.1）

- **如果**：逻辑参数为真进入子语句体，为假则跳过；执行后会跳过后续所有"否则"命令。
- **否则**：只能放在"如果"或其它"否则"命令后面。判断条件可省略（即单纯的否则），但省略后不能再后续跟随其它"否则"。

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 计数 <类型 = 整数>
如果 (计数 == 5)
{
    返回
}
否则
{
    // 其它分支
}
```

### 判断循环（3.1.2）

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 计数 <类型 = 整数>
变量 继续循环 <类型 = 逻辑型 值 = 真>
判断循环 (继续循环)
{
    计数 = 计数 + 1
    如果 (计数 == 5)
    {
        继续循环 = 假
    }
}
```

### 循环（3.1.3）

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 计数 <类型 = 整数>
循环 (, 10, 计数, 1)
{
    如果 (计数 == 5)
    {
        跳出循环
    }
}
```

**循环命令参数表**：

| 参数 | 类型 | 说明 |
|------|------|------|
| 变量起始值 | 整数[可省略] | 循环变量起始数值，省略默认0 |
| 变量目标值 | 整数[可省略] | 到达此目标值跳出，省略默认1 |
| 循环变量 | 整数[可省略] | 控制循环次数的变量，循环尾自动递增/递减 |
| 变量递增值 | 整数[可省略] | 每次执行到循环尾加入循环变量的值，必须提供**非0立即值**，省略默认1 |

**注意**：当递增值大于0时，循环变量值 `大于等于` 目标值时跳出；递增值小于0时，`小于等于` 目标值时跳出。

### 到循环尾 / 跳出循环（3.1.4）

```火山代码
变量 计数 <类型 = 整数>
循环 (, 10, 计数, 1)
{
    如果 (计数 == 5)
    {
        到循环尾    // 跳到循环体尾部继续下一次循环
    }
    如果 (计数 == 8)
    {
        跳出循环    // 完全退出循环
    }
}
```

**枚举循环**（附录A速查卡⑩）：容器对象的嵌入式无参方法，如 `文本数组.枚举循环 ()`，循环体内用 `取枚举值 ()`/`取枚举索引 ()`。

### 返回（3.1.5）

```火山代码
方法 测试方法 <公开>
参数 参数1 <类型 = 整数>
{
    如果 (参数1 == 5)
    {
        返回
    }
    返回
}
```

- 方法定义有非空返回值时，**必须**提供返回值；否则必须省略返回参数。

### 挂接事件 / 接收事件（附录A速查卡⑫ / 3.2）

```火山代码
方法 按钮_被单击 <接收事件>
参数 来源对象 <类型 = 按钮>
参数 标记值 <类型 = 整数>
{
}
```

- 命名格式：`类名_事件名` + `<接收事件>`，否则事件不触发（3.2：方法名格式为"事件所属类名_欲接收事件名"）；
- 手动挂接：`挂接事件 (对象, 标记值)`，标记值传给接收方法的 `标记值` 参数；取消挂接用关键字 `取消事件挂接 (对象)`（自动/手动挂接均可取消）；通用事件机制（`事件发送器`）则用对应实例的 `取消挂接 ()` 方法。

## 八、方法定义与特殊方法（3.2 / 3.3 / 3.4）

```火山代码
方法 方法 <公开 静态 类型 = 整数 注释 = "这是方法注释" 返回值注释 = "这是返回值注释">
参数 参数1 <类型 = 整数 注释 = "这是参数1注释">
参数 参数2 <类型 = 整数 注释 = "这是参数2注释">
{
    返回 (参数1 + 参数2)
}
```

**方法基本属性**：

| 属性 | 说明 |
|------|------|
| 返回值类型（类型） | 方法执行完毕后返回的数据类型 |
| 静态 | 静态方法通过"类名.方法名"引用；内部只能访问所在类或其基础类的成员常量或静态成员变量 |
| 公开 | 公开方法可在类外部访问 |
| 参数表 | 所有参数的定义行，顺序排列在方法定义行下方 |

**方法类别（类别属性）**：

| 类别 | 说明 | 格式要求 |
|------|------|---------|
| 通常 | 普通方法 | 无特殊要求 |
| 属性读 | 属性可在语句中被读取 | 非静态：无参数+必须有非数组返回值 |
| 属性写 | 属性可在语句中被赋值 | 非静态：无返回值+只能定义1个非数组参数 |
| 定义事件 | 定义本类对象将发送的事件 | 方法体必须为空；返回值必须为整数；不能为静态 |
| 接收事件 | 接收成员对象发送的事件 | 返回整数、非静态；方法名格式为"事件所属类名_欲接收事件名" |

**接收事件方法格式要求**：
- 第1个参数数据类型为欲接收其事件的事件源对象所属类；
- 第2个参数数据类型为整数，接收"挂接事件"调用所提供的标记值；
- 其余参数数目及类型必须与欲接收事件的定义方法一致。

**类_初始化**：类对象被创建时自动调用，不携带参数且不返回值：

```火山代码
类 测试类
{
    方法 类_初始化
    {

    }
}
```

**类_清理**：类对象被销毁时自动调用：

```火山代码
类 测试类
{
    方法 类_清理
    {

    }
}
```

### 参数的属性（3.4）

- **@默认值**：为参数提供调用方未提供对应数据时的默认值，须与参数数据类型匹配；数组/类/文本型参数可设为"空对象"。
- **@常量参数**：设置为真说明参数内容在方法内部不可被修改（仅非嵌入式方法）。
- **@匹配类型（参数增强通配模式）**（仅嵌入式方法参数，此时不能设置数据类型）：

| 值 | 匹配 |
|----|------|
| 通用整数型 | 所有非数组整数类型 |
| 通用数值型 | 所有非数组数值型类型 |
| 通用非文本基本型 | 非数组非文本基本类型 |
| 通用基本型 | 所有非数组基本数据类型 |
| 本地类 | 所有非数组本地类 |
| 通用类 | 所有非数组类定义数据类型 |
| 通用型 | 所有非数组数据类型 |
| 通用型数组等 | 对应数据类型的数组变体 |
| 所有类型 | 所有数组和非数组数据类型 |
| 等于前参数值类型 | 须与前方参数值数据类型一致 |

- **@需求类型**：
  1. **可写入变量**：调用方需提供可修改内容的变量，某些子平台以参考方式传递以向方法外部返回数据；
  2. **立即数或常量**：调用方需提供立即数或常量（仅嵌入式方法）；
  3. **数据类型**：调用方需提供数据类型名称（仅嵌入式方法）。
- **@可扩展**：仅嵌入式方法最后一个参数，调用时可被扩展。
- **@返回值类型**：仅嵌入式方法参数，指定方法的返回值数据类型为调用时提供的本参数数据的当前实际数据类型。

## 九、编译相关（3.5）

**按需编译**：火山编译器实行按需编译模式，凡是不可能被执行到的代码一概不编译。从程序启动位置开始，所有未在程序执行流程中的代码都不会被编译。

**命令行编译**（非免费版）：

```
voldev_xxx.exe @compile 欲编译火山项目解决方案文件名 [/r] [/c] [/d]
```

- `/r`：是否强制重新编译
- `/c`：是否仅生成目标代码而不进行本地编译
- `/d`：是否生成调试版（不设置则生成发布版）
- 编译成功进程返回值为 0，否则返回 -1。
