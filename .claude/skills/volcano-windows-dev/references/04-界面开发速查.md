## 7.1 界面体系总览（MFC 与 WTL 二选一）

火山视窗提供两套互斥的界面体系：**MFC界面基本类**（`w_mfc_ui_base.vgrp`）和 **WTL界面基本类**（`w_wtl_ui_base.vgrp`）。每个视窗项目必须选择其一（在项目属性中设定），二者不可混用。两套体系均提供顶层窗口类、容器组件类、消息过滤器、常用界面功能类、菜单类等核心基础设施，控件的 API 表现层高度相似，差异主要体现在底层实现（MFC 基于 CWnd/CWinApp，WTL 基于 ATL/WTL 模板类）以及部分高级控件的支持范围。

### 核心类与包名

| 类名 | 所属模块/包名 | 说明 |
|------|-------------|------|
| `窗口组件` | MFC/WTL 界面基本类 | 所有界面组件的根基类，提供位置、尺寸、标题、可视、禁止、字体、鼠标/键盘事件、鼠标指针等通用属性与方法 |
| `窗口容器组件` | MFC/WTL 界面基本类 | 可容纳子组件的容器类，提供子组件组显示/禁止、创建容器组件、取所有子组件句柄等方法 |
| `组件布局器` | MFC/WTL 界面基本类 | 窗口的布局管理基础类（各窗口类继承自它），提供底图、底色、布局等能力 |
| `窗口` | MFC/WTL 界面基本类 | 顶层窗口组件类，提供创建窗口/主窗口/对话框、菜单命令接收、窗口边框/外形/透明度等属性和事件。标记 `@可插入程序类`，可被 IDE 直接插入为窗口子类 |
| `菜单类` | MFC/WTL 界面基本类 | 菜单对象类，基础类为 `可设计类`，提供对应的菜单设计器。支持菜单项增删/选中/允许/禁止/标题/提示/图标等操作 |
| `常用界面功能类` | MFC/WTL 界面基本类 | `@全局类`，仅提供 `处理事件`、`界面延时` 两个静态方法。弹出托盘菜单、置/取/删除窗口属性、文件被拖放事件等均属于 `窗口组件` |
| `消息过滤器类` | MFC/WTL 界面基本类 | 提供 `挂接`/`挂接2`/`取消挂接` 方法，可挂接到窗口组件上以监视其消息。含 `消息过滤` 事件和 `变量 所挂接窗口句柄`(变整数) |
| `窗口程序类` | 火山.基本（base.vgrp） | 视窗程序启动类的基础类，基础类为 `程序类`。提供 `消息过滤`、`空闲`、`即将退出` 三个可覆盖虚方法 |
| `程序类` | 火山.基本（base.vgrp） | 所有程序启动类的根基类。提供 `取用户程序版本号`(小数)、`取火山平台版本号`(整数)、`取用户程序版本名`(文本型) 等静态方法 |
| `动态库程序类` | 火山.基本（base.vgrp） | 动态链接库程序的启动类。提供 `入口通知`、`将被卸载` 等可覆盖虚方法 |

> 注：MFC 与 WTL 版本的核心类名相同（如 `窗口`、`按钮`、`编辑框`），但在不同体系下引用不同的模块。项目属性中选择 MFC 则引用 `MFC界面基本类`，选择 WTL 则引用 `WTL界面基本类`。

### 最小窗口程序示例（MFC 版）

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

包 火山.用户.最小窗口示例

类 启动类 <公开 基础类 = 窗口程序类>
{
    变量 主窗口对象 <类型 = 主窗口>

    方法 启动方法 <公开 类型 = 整数>
    {
        // 创建主窗口（必须调用，且主窗口对象须为启动类成员变量）
        如果 (主窗口对象.创建主窗口 ())
        {
            返回 0
        }
        否则
        {
            返回 -1
        }
    }

    方法 即将退出 <公开>
    {
        // 程序退出前的清理工作（可覆盖）
    }
}

类 主窗口 <公开 基础类 = 窗口 注释 = "示例主窗口">
{
    方法 窗口_接收到命令 <接收事件> 参数 来源对象 <类型 = 窗口> 参数 命令代码 <类型 = 整数>
    {
        返回 0
    }

    方法 窗口_窗口可否被关闭 <接收事件> 参数 来源对象 <类型 = 窗口>
    {
        返回 0
    }
}
```

> **注意事项**：界面程序启动类必须继承 `窗口程序类`；控制台/无窗口程序启动类直接继承 `程序类`；主窗口对象必须是启动类中的**成员变量**（不能是 `启动方法` 中的局部变量），否则窗口创建后对象析构导致崩溃；程序中只能存在一个主窗口（`创建主窗口` 或 `置为主窗口` 只能调用一次）。

## 7.2 窗口程序类与启动流程

### 核心类

| 类名 | 基础类 | 所属模块 | 说明 |
|------|--------|---------|------|
| `程序类` | 程序基础类 | 火山.基本 | 所有程序启动类的根基类。`@禁止创建对象` |
| `窗口程序类` | 程序类 | 火山.基本 | 基于窗口的用户程序启动类。`@禁止创建对象`。提供三个可覆盖虚方法 |
| `动态库程序类` | 程序类 | 火山.基本 | 动态链接库程序的启动类。`@禁止创建对象` |
| `窗口` | 组件布局器 | MFC/WTL界面基本类 | 顶层窗口组件类。标签 `@可插入程序类` 表示用户可在 IDE 中直接插入窗口子类 |

### 窗口程序类的方法（启动类可覆盖的虚方法）

| 方法名 | 返回值 | 虚方法 | 说明 |
|--------|--------|--------|------|
| `消息过滤` | 逻辑型 | 可覆盖 | 过滤处理程序中所有窗口的消息。返回真允许继续传递，返回假取消。参数：窗口句柄(变整数)、消息值(整数)、消息参数1(变整数)、消息参数2(变整数)、消息地址(变整数) |
| `空闲` | 逻辑型 | 可覆盖 | 系统空闲时调用。参数：已空闲时间(整数，单位毫秒)。返回假则本次空闲期间不再调用（降低CPU占用），返回真则继续调用 |
| `即将退出` | - | 可覆盖 | 窗口程序退出前调用，用于执行清理工作（释放资源、保存配置等） |

### 程序类的静态方法

| 方法名 | 返回值 | 静态 | 说明 |
|--------|--------|------|------|
| `取用户程序版本号` | 小数 | 是 | 返回项目设置中设定的程序版本号 |
| `取用户程序次版本号` | 小数 | 是 | 返回项目设置中设定的程序次版本号 |
| `取用户程序版本名` | 文本型 | 是 | 返回项目设置中设定的程序版本名称文本 |
| `取火山平台版本号` | 整数 | 是 | 返回编译此程序时所使用的火山平台版本号 |

### 窗口类的创建方法

| 方法名 | 返回值 | 说明 |
|--------|--------|------|
| `创建窗口` | 逻辑型 | 创建本窗口类的对象（非主窗口）。参数均可省略，省略时使用设计时默认值 |
| `创建有菜单窗口` | 逻辑型 | 创建窗口，第一参数指定菜单类的数据类型（`@需求类型`:"数据类型"） |
| `创建主窗口` | 逻辑型 | 创建并设为主窗口。程序必须且只能存在一个主窗口。**主窗口必须在启动类中定义为成员变量** |
| `创建有菜单主窗口` | 逻辑型 | 创建带菜单主窗口，第一参数为菜单数据类型 |
| `置为主窗口` | - | 将已有窗口对象设置为主窗口（不再调用创建主窗口） |
| `创建子窗口` | 逻辑型 | 创建为其他窗口的子窗口（非主窗口），显示内容位于父窗口之上且被裁剪 |
| `创建弹出子窗口` | 逻辑型 | 创建为弹出风格子窗口（非主窗口），显示内容独立存在且不被父窗口裁剪 |
| `创建对话框` | 整数 | 以模态对话框方式创建并显示，等待关闭后返回。不能动态调整尺寸/位置，初始居中。返回值为调用 `关闭窗口` 时提供的结果值；Alt+F4/ESC/关闭按钮关闭则返回-1 |

**创建窗口方法的参数（以 `创建窗口` 为例）**：

| 参数名 | 数据类型 | 默认值 | 说明 |
|--------|---------|-------|------|
| 左边位置 | 整数 | 数值范围.最小整数值 | 屏幕横向坐标，最小整数值表示横向居中 |
| 顶边位置 | 整数 | 数值范围.最小整数值 | 屏幕纵向坐标，最小整数值表示纵向居中 |
| 宽度 | 整数 | 数值范围.最小整数值 | 窗口宽度，最小整数值表示使用设计时宽度 |
| 高度 | 整数 | 数值范围.最小整数值 | 窗口高度，最小整数值表示使用设计时高度 |
| 所欲使用的菜单 | 菜单类 | 空对象 | 同时设置的窗口菜单，空对象表示无 |

### 窗口外观属性

| 属性名 | 数据类型 | 设置时机 | 说明 |
|--------|---------|---------|------|
| `窗口边框` | 窗口边框类型 | 创建前后 | 窗口边框类型，默认"普通固定边框" |
| `控制按钮` | 逻辑型 | 创建前后 | 是否显示控制按钮及窗口控制菜单 |
| `可否移动` | 逻辑型 | 创建前后 | 窗口位置可否被移动 |
| `图标` | 图标资源 | 创建前后 | 窗口左上角图标 |
| `图标对象` | 图标对象类 | 创建前后 | 通过图标对象设置窗口图标。**窗口存在期间必须保证图标对象不被释放**（需保存在窗口类成员变量中） |
| `Esc键关闭` | 逻辑型 | 创建前后 | 是否允许 ESC 键关闭窗口（默认真）。对话框方式下无论本属性设置始终允许 |
| `帮助文件名` | 文本型 | 创建前后 | F1键打开帮助文件的路径。空文本表示不支持。调试时可使用 `@视窗.附属文件` 自动拷贝 |
| `帮助标记值` | 整数 | 创建前后 | 帮助文件中的标志数值，0对应主题位置 |
| `随意移动` | 逻辑型 | 创建前后 | 窗口任意位置按下鼠标即可整体移动（默认为假）。设为真后窗口内不可获焦子组件不再接收鼠标按下/放开事件 |
| `外形` | 窗口外形类型 | 创建前后 | 窗口外形，默认"矩形" |
| `总在最前` | 逻辑型 | 创建前后 | 是否永远位于其他窗口前面（默认为假） |
| `保持标题条激活` | 逻辑型 | 创建前后 | 非激活状态下标题条是否保持激活状态外观（默认为假） |
| `透明度` | 整数 | - | 窗口透明度（0=完全透明, 255=完全不透明） |
| `窗口类名` | 文本型 | 创建前 | Windows 系统窗口类名，该名称会在创建时自动登记 |

### 窗口核心事件

| 事件名 | 返回值 | 说明 |
|--------|--------|------|
| `接收到命令` | 整数 | 菜单项/工具条按钮被单击或快捷键被按下时触发。参数：命令代码(整数)。返回1表示已处理 |
| `命令被选中` | 整数 | 鼠标移动到菜单项/工具条按钮上时触发。参数：命令代码(整数)。菜单关闭或鼠标移开时命令代码=0 |
| `可否被关闭` | 整数 | 窗口及计算机被关闭前触发。**包含关机通知**。返回1不允许关闭 |
| `窗口可否被关闭` | 整数 | 窗口被关闭前触发。**不包含**关机通知。返回1不允许关闭 |
| `首次激活` | 整数 | 窗口创建完毕后首次激活显示时触发。可在此开始画板写出操作 |
| `被激活` | 整数 | 窗口转换为激活状态时触发 |
| `被取消激活` | 整数 | 窗口转换为非激活状态时触发 |
| `托盘事件` | 整数 | 用户操作托盘图标时触发。参数：操作类型(整数，1=单击左键, 2=双击左键, 3=单击右键) |
| `位置限制` | 整数 | 可修改参数限定窗口尺寸/位置。参数：位置限制信息(窗口位置限制信息)。返回1表示已处理 |
| `对话框已初始化` | 整数 | 以对话框方式创建窗口后触发。可在此初始化窗口内容 |
| `消息过滤` | 逻辑型 | **可覆盖方法**。过滤窗口及其子组件的键盘/鼠标消息。参数：窗口句柄(变整数)、消息值(整数)、消息参数1(变整数)、消息参数2(变整数)、消息地址(变整数)。返回真允许继续传递 |

### 以模态对话框方式创建窗口的示例

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

包 火山.用户.对话框示例

类 启动类 <公开 基础类 = 窗口程序类>
{
    方法 启动方法 <公开 类型 = 整数>
    {
        // 先创建主窗口
        变量 主窗口对象 <类型 = 主窗口>
        主窗口对象.创建主窗口 ()

        // 再以对话框方式弹出一个设置窗口
        变量 设置对话框 <类型 = 设置窗口>
        变量 结果值 <类型 = 整数>
        结果值 = 设置对话框.创建对话框 (真)
        // 结果值即为用户在对话框中调用"关闭窗口"提供的值
        // 用户按ESC/Alt+F4或点击关闭按钮则返回-1

        返回 0
    }
}

类 主窗口 <公开 基础类 = 窗口>
```

> **注意事项**：
> - `启动方法` 中主窗口对象必须是**启动类的成员变量**，`创建对话框` 方式创建的窗口对象可以是局部变量（因为 `创建对话框` 是同步阻塞的，返回后窗口已关闭）。
> - 事件接收方法命名必须遵循 `类名_事件名` 格式，如 `主窗口_窗口可否被关闭`。其中 `类名` 为接收事件方法所在的类名（即当前窗口子类的名称）。
> - `消息过滤` 是**可覆盖虚方法**而非事件：它在当前类中直接覆盖实现（不标注 `<接收事件>`），且返回值类型为逻辑型。
> - 注意：`询问信息框` 返回**逻辑型**（点"是"返回真），按返回值判断即可，不要与 `信息框` 的 `返回按钮类型` 混淆。

### 7.3.9 控件综合事件接收示例

窗口包含按钮、编辑框、组合框、时钟的综合事件接收示例：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

包 火山.用户.控件事件示例

类 启动类 <公开 基础类 = 窗口程序类>
{
    变量 主窗口对象 <类型 = 控件示例窗口>

    方法 启动方法 <公开 类型 = 整数>
    {
        主窗口对象.创建主窗口 ()
        返回 0
    }
}

类 控件示例窗口 <公开 基础类 = 窗口>
{
    // 控件成员变量：非静态成员变量默认自动挂接事件到本类
    变量 提交按钮 <类型 = 按钮>
    变量 输入区 <类型 = 编辑框>
    变量 城市列表 <类型 = 组合框>
    变量 主选项卡 <类型 = 选择夹>
    变量 定时器1 <类型 = 时钟>
    变量 记住密码 <类型 = 选择框>

    // 按钮单击（事件接收方法名称 = 事件对象类名 + "_" + 事件名）
    方法 按钮_被单击 <接收事件 类型 = 整数>
    参数 来源对象 <类型 = 按钮>
    参数 标记值 <类型 = 整数>
    {
        如果 (来源对象 == 提交按钮)
        {
            信息框 ("提交按钮被按下！")
        }
        返回 0
    }

    // 编辑框内容改变
    方法 编辑框_内容被改变 <接收事件 类型 = 整数>
    参数 来源对象 <类型 = 编辑框>
    参数 标记值 <类型 = 整数>
    {
        变量 当前内容 <类型 = 文本型>
        当前内容 = 来源对象.内容
        调试输出 ("当前输入：" + 当前内容)
        返回 0
    }

    // 组合框列表项选择
    方法 组合框_列表项被选择 <接收事件 类型 = 整数>
    参数 来源对象 <类型 = 组合框>
    参数 标记值 <类型 = 整数>
    {
        变量 选中项 <类型 = 整数>
        变量 选中文本 <类型 = 文本型>
        选中项 = 来源对象.现行选中项
        如果 (选中项 >= 0)
        {
            选中文本 = 来源对象.取项目文本 (选中项)
            调试输出 ("选中城市：" + 选中文本)
        }
        返回 0
    }

    // 选择夹子夹切换
    方法 选择夹_子夹被改变 <接收事件 类型 = 整数>
    参数 来源对象 <类型 = 选择夹>
    参数 标记值 <类型 = 整数>
    {
        调试输出 ("子夹已被切换")
        返回 0
    }

    // 时钟周期事件
    方法 时钟_周期事件 <接收事件 类型 = 整数>
    参数 来源对象 <类型 = 时钟>
    参数 标记值 <类型 = 整数>
    {
        // 每秒更新时间显示
        调试输出 ("定时器触发")
        返回 0
    }

    // 选择框单击（读取点击前的选中状态）
    方法 选择框_被单击 <接收事件 类型 = 整数>
    参数 来源对象 <类型 = 选择框>
    参数 标记值 <类型 = 整数>
    {
        如果 (来源对象.选中)
        {
            调试输出 ("选择框当前为选中状态，点击后将取消选中")
        }
        否则
        {
            调试输出 ("选择框当前未选中，点击后将选中")
        }
        返回 0
    }
}
```

> **注意事项（事件接收方法规范）**：
> - 事件接收方法命名必须为 `类名_事件名`（如 `按钮_被单击`、`时钟_周期事件`），其中"类名"为定义事件的对象类名；方法必须声明 `<接收事件>`，返回值数据类型必须为整数。
> - 事件接收方法的前两个参数固定为：`来源对象`（数据类型必须为事件对象类名）与 `标记值`（整数，自动挂接方式下固定为0）；其后参数与事件定义方法的参数一致。
> - `来源对象` 参数的类型必须与控件类名严格一致（如 `按钮` 控件事件用 `<类型 = 按钮>`，不可用 `<类型 = 窗口组件>` 代替）。
> - 非静态控件成员变量默认自动挂接事件到本类（可用 `@自动挂接事件` 属性关闭）；动态创建的组件不会自动挂接，需使用 `挂接事件 (对象, 标记值)` 命令手动挂接后其事件才能被接收。

## 7.5 WTL 界面体系要点

WTL（Windows Template Library）是微软发布的基于 ATL 的轻量级窗口模板库。火山视窗中的 WTL 界面基本类与 MFC 界面基本类在 API 层面保持高度一致——同名类提供相同的属性、方法和事件签名，上层代码几乎可零修改迁移（仅需修改项目属性中的界面体系选择）。

**两套体系核心类对照（同名、基础类一致、API 完全一致）**：`窗口`(均继承 `组件布局器`，均标记 `@输出名="@CVolWinForm"`)、`窗口组件`、`窗口容器组件`、`菜单类`(均继承 `可设计类`)、`消息过滤器类`、`常用界面功能类`、`按钮`(均继承 `按钮基础类`)、`编辑框`、`组合框`、`列表框`(均继承 `列表框基础类`)、`选择框`/`单选框`/`三态选择框`、`标签`、`图片框`(均继承 `组件布局器`)、`选择夹`(均继承 `窗口容器组件`)、`外形框`、`画板`、`滚动条`/`进度条`/`滑块条`、`日期框`/`月历`、`驱动器框`/`目录框`/`文件框`、`时钟`、`图形按钮`、`热键框`、`影像框`、`通用对话框`、`颜色选择器`、`调节器`、`打印机`、`OCX组件`。

**WTL 与 MFC 的核心差异**：

1. **文件体积与运行时依赖**：WTL 基于 ATL/WTL 模板类，编译产物通常显著小于 MFC 版本，且不需要分发的 MFC DLL（mfc140u.dll 等）。在需要轻量部署的场景下优势明显。
2. **高级控件生态**：MDI 多文档界面、MFC 表格(`w_mfc_ui_grid`)、属性表格(`w_mfc_property_grid`) 等模块无 WTL 版（仅限 MFC 体系使用）。卷帘式菜单官方同时提供 WTL 卷帘式菜单组件（`wtl_ui_out_bar.vgrp`），WTL 体系可直接使用。
3. **消息过滤机制**：两套体系的 `消息过滤` 虚方法参数签名完全一致——均接收窗口句柄(变整数)、消息值(整数)、消息参数1(变整数)、消息参数2(变整数)、消息地址(变整数)。启动类的 `消息过滤` 和窗口类的 `消息过滤` 覆盖方式相同。
4. **启动流程一致**：无论选择哪种界面体系，启动类均继承 `窗口程序类`（`火山.基本`），由项目设置决定最终链接的底层窗口库。`创建主窗口`、`创建对话框` 等方法的调用方式完全一致。
5. **设计器兼容性**：IDE 可视化设计器对两套体系的支持程度基本相同，拖放控件自动生成对应体系的布局代码。

**适用建议**：

- **推荐 MFC 的场景**：项目需要 MDI、高级表格/属性表格/卷帘式菜单等 MFC 专有控件；团队对 MFC 体系更熟悉；对可执行文件体积不敏感。
- **推荐 WTL 的场景**：目标生成轻量级可执行文件；不需要 MFC 专有高级控件；希望减少对系统 MFC DLL 的依赖；对编译速度有要求（WTL 模板展开较慢但最终体积小）。
- **注意**：如果项目启动后需要切换界面体系，上层代码 API 一致无需修改，但需重新编译全部模块并确认无 MFC 专有类引用。

## 7.7 本章易错点总结

> **注意事项**：以下为本章涉及的常见开发易错点，建议在项目开发过程中逐一核对。

1. **MFC 与 WTL 界面体系混用**：项目属性中一旦选定界面体系，所有界面组件必须使用对应体系模块的类。混用（如 MFC 项目的窗口引入 WTL 控件）会导致编译时符号冲突或运行时崩溃。高级控件模块（MDI、表格、属性表格等）通常仅支持 MFC 体系，使用前务必确认模块兼容性。

2. **主窗口对象为局部变量**：主窗口对象必须是 `启动类` 的成员变量（`变量 主窗口对象 <类型 = 主窗口>`），而不能是 `启动方法` 中的局部变量。若为局部变量，`启动方法` 返回后对象析构、窗口随之销毁，导致程序立即退出。`创建对话框` 方式创建的窗口可以是局部变量（因为 `创建对话框` 是同步阻塞调用）。

3. **控件事件接收方法命名不规范导致事件不触发**：事件接收方法命名错误或参数类型不匹配时，事件静默失效且无编译警告。（V2.5修正：命名格式以 `类名_事件名` 为准，如 `按钮_被单击`、`按钮_提交_鼠标左键被按下` 示例格式不再适用；）类名和事件名均需与接口文件中定义的一致。`来源对象` 参数的类型必须与控件类严格匹配。

4. **"创建前"属性在创建后设置无效**：编辑框的 `是否允许多行`、`隐藏选择`、`滚动条`、`对齐方式`，按钮的 `类型`，组合框/列表框的 `自动排序`、`多列`、`行间距`、`允许多行表头`、`表头方向` 等属性标注为 `@视窗.设置时机` = `"组件创建前"`。组件创建后再修改这些属性无效，必须在设计器属性面板或代码中组件创建前设置。

5. **窗口类名(`窗口类名`属性)的时机限制**：`窗口类名` 属性的设置时机为"组件创建前"，且提供的类名会在窗口创建时自动登记到 Windows 系统中。创建后修改无效。

6. **图标对象的生命周期管理**：通过 `图标对象` 属性设置的图标，在窗口存在期间必须保证图标对象不被释放（应将其保存在窗口类的成员变量中），否则置入的图标将变成无效。

7. **消息循环阻塞导致界面假死**：在主窗口事件处理方法或控件事件中执行耗时操作（同步网络请求、大量文件 IO、长时间循环）会阻塞 Windows 消息循环，导致界面无响应。耗时操作应放入子线程执行，并通过 `投递信息`、`调用反馈事件` 等线程安全方式通知主线程更新界面。

8. **高 DPI 适配**：在 Windows 高 DPI 显示设置下，若程序未在清单中声明 DPI 感知模式，系统会对窗口进行缩放导致模糊。`窗口组件` 的位置/尺寸方法返回的是像素坐标，在 DPI 缩放环境中需注意逻辑坐标与物理像素的转换。

9. **菜单项 ID 重复导致插入失败**：`插入菜单项` 方法的 `新菜单项ID` 参数必须尚不存在于当前菜单中。若传入已存在的 ID，方法将失败返回0。建议传0让系统自动分配不重复的ID。

10. **`可否被关闭` 与 `窗口可否被关闭` 的区别**：`可否被关闭` 同时包含窗口关闭和计算机关机两种场景；`窗口可否被关闭` 仅包含窗口关闭（不含关机）。在需要区分关机与关闭的场景下，需在不同事件中分别处理。
