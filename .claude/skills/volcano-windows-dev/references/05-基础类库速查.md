## 6.1 对象模型基础（对象类）

火山平台基于面向对象理念，所有用户类都必须为 **CVolObject** C++ 类的继承类。`对象类` 是所有火山类的默认基础类——如果某类未明确指定基础类，则其基础类自动为本类。

### 6.1.1 对象类的核心方法

| 方法 | 数据类型 | 说明 |
|------|---------|------|
| `标记值` | 变整数 | 返回/设置本对象中设置的用户标记数值（初始 0） |
| `为指定对象类` | 逻辑型 | 返回本对象的实际数据类型是否为所指定的类 |
| `匹配指定对象类` | 逻辑型 | 返回实际数据类型是否匹配所指定的类（或其继承类），等效于"属于"操作符 |
| `对象类型是否相同` | 逻辑型 | 返回两个对象的实际数据类型是否相同 |
| `对象内容是否相同` | 逻辑型 | 返回两个对象的数据内容是否相同（注意：比较操作符 `==` 只比较对象地址） |
| `新建对象` | 对象类 | 创建一个新的同类实例对象 |
| `检查复制对象` | 逻辑型 | 检查/复制对象数据 |
| `重置对象内容` | - | 将对象内容重置为初始状态 |
| `是否为空对象` | 逻辑型 | 返回本对象是否设置了"空白对象"标志 |
| `取对象自身指针` | 变整数 | 取本对象的 C++ 对象指针 |
| `取对象类输出名` | 文本型 | 返回本对象的类输出名 |
| `取对象数据` / `置对象数据` | 字节集类 | 基于流操作获取 / 设置本对象中的所有内容数据 |

> 说明：`取展示内容`、`流读入`、`流写出` 属 `扩展对象类`（基础类为 `对象类`，`取展示内容` 为可覆盖虚拟方法，展示文本以文本型出参填入）。

**典型用法示例**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 对象1 <类型 = 对象类>
变量 对象2 <类型 = 对象类>

对象1.标记值 = 100
如果 (对象1.标记值 == 100)
{
    调试输出 ("标记值正确")
}

// 比较数据内容（而非对象地址）
如果 (对象内容是否相同 (对象1, 对象2))
{
    调试输出 ("两个对象内容相同")
}
```

### 6.1.2 对象比较的易错点

- 使用比较操作符 `==` / `!=` 比较类对象时，比较的是**对象地址**是否相同；
- 欲比较两个对象的数据内容，必须使用 `对象内容是否相同` 方法；
- **字节集类**：比较内容使用 `字节集内容是否相同`（或 `对象内容是否相同`，两者等效），`==` 操作符同样仅比较对象地址；
- 文本型对象比较的是实际内容（区分大小写），也可与"空对象"比较。

> **注意事项**：`匹配指定对象类` 支持继承类匹配（对象是子类实例也返回真），`为指定对象类` 要求完全一致。判断"对象是否为某类实例"时优先使用"属于"操作符或 `匹配指定对象类`。

### 6.1.3 对象包装、指针与结构类

- **对象包装类**：把基本数据（字节/短整数/字符/整数/变整数/长整数/单精度小数/小数/逻辑型）包装为对象（文本型本身即类无需包装），便于作为对象传递；
- **指针类**：`置指针`、`读`、`写`、`清除`、`是否为空`；指针族类（`文本指针`、`本地结构指针模板` 等）提供 `取指针`，`本地结构指针模板` 另有 `取数据尺寸`、`取变整数指针`、`创建`/`销毁`；
- **结构基础类**：`取结构指针`、`取结构尺寸`、`取结构字节集`，用于与本地结构交互；
- **事件发送器**：`挂接`、`取消挂接`、`是否已挂接`、`发送事件`，用于自定义事件机制；事件接收方由 `事件接收器` 类提供 `接收到事件`。

## 6.2 文本类（Unicode-16 文本处理）

火山系统默认文本字符集为 **Unicode-16**（CVolString）。`文本类`（`火山.基本`）提供最完整的文本操作。

### 6.2.1 关键方法分类

| 类别 | 方法 |
|------|------|
| 长度/截取 | `取文本长度`、`置文本长度`、`取文本左边`、`取文本右边`、`取文本中间` |
| 查找 | `寻找文本`、`倒找文本` |
| 分割 | `分割文本`、`分割子文本` |
| 替换 | `文本替换`、`子文本替换`、`替换所有子文本` |
| 修剪/转换 | `删首尾空`、`到大写`、`到小写`、`到全角`、`到半角` |
| 拼接 | `到文本`、`置文本`、`取格式文本`、`加入格式文本` |
| 编码 | `文本到UTF8`、`UTF8到文本`、`文本到多字节`、`文本到字节集`、`字节集到文本`、`取当前代码页` |
| 文件 | `读入文本文件`、`写出文本文件` |
| 其它 | `简繁转换`、`文本比较`、`近似等于`、`取文本哈希值` |

**文本拼接与格式化示例**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 姓名 <类型 = 文本型 值 = "张三">
变量 年龄 <类型 = 整数 值 = 30>
变量 结果 <类型 = 文本型>

// 方式一：直接拼接
结果 = "姓名：" + 姓名 + "，年龄：" + 到文本 (年龄)

// 方式二：格式化
结果 = 取格式文本 ("姓名：%s，年龄：%d", 姓名, 年龄)

// 查找与替换
变量 索引 <类型 = 整数>
索引 = 寻找文本 (结果, "张三")
如果 (索引 >= 0)
{
    结果 = 替换所有子文本 (结果, "张三", "李四")
}
```

**编码转换示例**：

```火山代码
变量 原文 <类型 = 文本型 值 = "你好，火山！">
变量 UTF8字节集 <类型 = 字节集类>
变量 字节集 <类型 = 字节集类>

UTF8字节集 = 文本到UTF8 (原文)          // 转换为 UTF-8 编码字节集（第2参 是否包括结束零字符@真）
字节集 = 文本到字节集 (原文)          // 转换为字节集
原文 = 字节集到文本 (字节集)          // 还原
```

> **注意事项**：`取文本长度` 返回的是字符数而非字节数；`寻找文本` 的起始搜寻位置参数从 0 开始（默认 0 代表首字符）；`分割文本` 支持按指定分隔符拆分为文本数组。

## 6.3 数组类

数组类库提供对各类数组的通用操作。核心类为 `基本数组操作类`，并派生出 `整数数组类`、`文本数组类`、`字节集数组类`、`对象数组类`、`结构数组模板类` 等。

### 6.3.1 通用数组方法

| 类别 | 方法 |
|------|------|
| 查询 | `取成员数`、`取最大索引`、`是否为空`、`预分配尺寸` |
| 枚举 | `枚举循环`、`逆向枚举循环`、`取枚举值`、`取枚举索引` |
| 增删 | `加入成员`、`加入空成员`、`批量加入新成员`、`插入成员`、`删除成员`、`删除所有成员`、`删除到尾部`、`清零`、`重置数组` |
| 读写 | `取成员`、`置成员值`、`交换成员` |
| 排序查找 | `排序`、`查找成员`、`查找首成员`、`查找尾成员`、`查找删除成员` |
| 批量 | `添加数组`、`添加字节集`、`从数组复制`、`取数组指针` |
| 序列化 | `流读入`、`流写出` |

**数组增删与枚举示例**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 文本数组 <类型 = 文本数组类>
变量 计数 <类型 = 整数>

// 加入成员
文本数组.加入成员 ("苹果")
文本数组.加入成员 ("香蕉")
文本数组.加入成员 ("橙子")

// 插入与删除
文本数组.插入成员 (1, "葡萄")           // 在索引 1 处插入
文本数组.删除成员 (0)                    // 删除索引 0 的成员

// 枚举循环遍历（嵌入式无参方法，循环体内取枚举值）
文本数组.枚举循环 ()
{
    调试输出 (文本数组.取枚举值 ())
}

// 按值查找索引：文本排序数组类 提供 查找成员（返回索引，未找到为 -1）
变量 排序数组 <类型 = 文本排序数组类>
排序数组.加入成员 ("苹果")
排序数组.加入成员 ("香蕉")
如果 (排序数组.查找成员 ("苹果") > -1)
{
    调试输出 ("找到苹果")
}
```

> **注意事项**：数组索引从 0 开始（`取最大索引` = 成员数 - 1）；`枚举循环` 是容器对象的嵌入式无参方法，循环体内用 `取枚举值 ()`/`取枚举索引 ()`；文本排序数组类（如 `文本排序数组类`）在加入成员时自动保持有序，适合频繁查找的场景。

## 6.4 字节集类（二进制数据）

`字节集类` 提供对二进制数据（字节集）的操作支持，同时提供 BASE64 编码方式。

### 6.4.1 关键方法分类

| 类别 | 方法 |
|------|------|
| 长度/分配 | `取字节集长度`、`取字节集值数目`、`分配字节集`、`重分配字节集`、`释放字节集`、`清空字节集` |
| 指针 | `取字节集指针` |
| 截取 | `取字节集左边`、`取字节集右边`、`取字节集中间` |
| 查找分割 | `寻找字节集`、`倒找字节集`、`分割字节集` |
| 替换 | `字节集替换`、`子字节集替换` |
| 增删 | `添加字节集`、`添加文本到字节集`、`添加值到字节集`、`插入字节集`、`插入文本到字节集`、`字节集删除`、`删除字节集尾部数据` |
| 文件 | `从文件读字节集`、`写字节集到文件` |
| 编码 | `字节集到十六进制文本`、`十六进制文本到字节集`、`字节集到BASE64文本`（编码格式取 `BASE64编码方式` 常量：标准/URL专用/正则专用，每行最大字符数@0）、`BASE64文本到字节集`、`字节集到Quoted文本` |
| 比较哈希 | `字节集内容是否相同`、`取字节集哈希值` |

**字节集读写与编码示例**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 字节集 <类型 = 字节集类>
变量 文本 <类型 = 文本型>

// 文本转字节集，再转十六进制
字节集 = 文本到字节集 ("Hello Volcano")
文本 = 字节集到十六进制文本 (字节集)

// BASE64 编码
文本 = 字节集到BASE64文本 (字节集)

// 从文件读取（返回整数为实际读入尺寸，-1 表示失败）
从文件读字节集 (字节集, "C:\\data\\config.bin")
```

> **注意事项**：`取字节集指针` 返回可变指针，修改指针指向的内存需确保已分配足够空间；`分配字节集` 与 `重分配字节集` 是底层操作，普通开发多用 `从文件读字节集`、`添加字节集` 等高层方法。

## 6.5 流操作（数据读写）

流类库提供统一的"数据读写"抽象。核心类：`基本流类`（基类）、`输入流类`、`输出流类`，以及具体实现 `文件输入/输出流`、`加密文件输入/输出流`、`内存输入/输出流`。

### 6.5.1 基本流类方法

| 类别 | 方法 |
|------|------|
| 状态 | `关闭`、`流是否为空`、`错误码`、`清除错误`、`是否成功`、`是否出错`、`重置` |
| 输入流 | `前移`、`是否到尾部`、`取读位置`、`读数据`、`读数据2`、`读内存`、`读到尾部`、`读`、`读对象`、`读数组` |
| 输出流 | `刷新`、`写数据`、`写内存`、`写`、`写对象`、`写数组` |

**文件读写示例**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 输出流 <类型 = 文件输出流>
变量 输入流 <类型 = 文件输入流>
变量 内容 <类型 = 文本型>
变量 读出 <类型 = 字节集类>

// 写出文本到文件：写数据接受字节集，文本经 文本到字节集 转换
输出流.打开 ("C:\\out\\data.txt")
输出流.写数据 (文本到字节集 ("火山视窗流操作测试"))
输出流.刷新 ()
输出流.关闭 ()

// 从文件读入：读到尾部 将全部剩余数据写入字节集，再转文本
输入流.打开 ("C:\\out\\data.txt")
输入流.读到尾部 (读出)
内容 = 字节集到文本 (读出)
输入流.关闭 ()
调试输出 (内容)
```

> 注：流对象无 `写文本`/`读全部文本` 方法——文本写入用 `写数据 (文本到字节集 (...))`，读取全部剩余数据用 `读到尾部 (出参字节集类)`，按指定尺寸读取用 `读数据 (所欲读入数据尺寸, 所欲保存到的字节集)`；`写` 按值/对象写出，`写内存`/`写对象`/`写数组` 为对应类型专用。

**内存流使用**：`内存输入流`/`内存输出流` 提供 `打开`、`置预分配尺寸`、`清空`、`取数据`，适合在内存中缓存数据后一次性取出。

> **注意事项（V2.5修正）**：使用完流对象建议 `关闭`（非必需，流对象销毁时自动关闭，关闭会清除流中现有出错状态）；`刷新` 将缓冲区数据真正写入底层设备；`是否出错` 可检查流操作是否发生错误。

## 6.6 异常处理

异常支持用于俘获/抛出异常。核心类：`基本火山异常类`（异常代码/异常描述属性）、`异常管理`。

### 6.6.1 异常管理方法

| 方法 | 说明 |
|------|------|
| `开始俘获异常` | 开始俘获异常 |
| `俘获异常` | 俘获异常 |
| `取被俘获异常数据` | 取被俘获的异常数据 |
| `俘获火山异常` | 俘获火山异常 |
| `取被俘获火山异常` | 取被俘获的火山异常 |
| `俘获所有异常` | 俘获所有异常 |
| `抛出异常` | 主动抛出异常 |
| `抛出火山异常` | 抛出火山异常 |
| `再次抛出异常` | 再次抛出异常 |

**俘获异常示例（嵌入式形态：俘获语句紧跟开始俘获异常语句体）**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

异常管理.开始俘获异常 ()
{
    // 可能产生异常的代码：抛出携带整数的异常
    异常管理.抛出异常 (666)
}
俘获异常 (整数)
{
    // 仅俘获数据类型为"整数"的异常，子语句体内取回所抛出的数据
    变量 错误码 <类型 = 整数>
    错误码 = 异常管理.取被俘获异常数据 (整数)
    调试输出 ("捕获到整数异常：" + 错误码)
}
俘获火山异常 ()
{
    // 俘获火山异常对象，可读取 异常代码/异常描述 属性
    调试输出 ("捕获到火山异常：" + 异常管理.取被俘获火山异常 ().异常描述)
}
俘获所有异常 ()
{
    // 俘获其余所有异常，覆盖范围最广，慎用
    调试输出 ("捕获到未知异常")
}
```

> **注意事项**：俘获语句须紧跟 `开始俘获异常` 语句体之后按序书写，可并列多个 `俘获异常`/`俘获火山异常`/`俘获所有异常`；其子语句体内可用 `取被俘获异常数据 (类型)`/`取被俘获火山异常 ()` 取回俘获数据，`再次抛出异常` 亦仅限俘获子语句体中使用。异常俘获应尽量缩小范围，`俘获所有异常` 覆盖范围最广，慎用。异常描述文本可记录到日志（见第18章 plog 用法）辅助排错。

## 6.7 多线程

多线程类库提供线程、线程池与同步原语。核心类：`线程类`、`全局线程池`、`缓存线程类`、`主线程处理器`，以及 `互斥锁类`、`信号灯类`、`同步事件类`、`读写锁类`、原子类型类。

### 6.7.1 线程类方法

| 方法 | 说明 |
|------|------|
| `启动 (堆栈尺寸@0)` | 启动线程，开始执行"线程运行"事件处理方法，成功返回真 |
| `是否正在运行 ()` | 线程是否正在运行 |
| `停止 ()` | 通知并等待"线程运行"事件处理方法退出（仅限线程外调用） |
| `通知停止 ()` | 仅发出退出通知，不等待退出 |
| `是否需要退出 (最大检查等待时间@10)` | 在"线程运行"处理方法中频繁调用，返回真须尽快退出 |
| `线程运行` | 定义事件，在线程中运行的处理方法，不可直接操作界面 |

此外，全局类 `线程操作类` 提供 `启动线程 (线程函数, 用户参数@0, 堆栈尺寸@0, 优先级@线程优先级.通常, 是否等待线程执行完毕@假)`、`线程模板函数1/2`、`启动有状态线程`、`等待多个事件`、`取当前线程ID`、`是否为主线程` 等静态操作；`线程状态类`（提供线程当前状态，供 `启动有状态线程` 绑定使用）提供 `置用户值`/`取用户值`/`置用户对象1/2`/`通知并等待线程退出`/`线程是否被通知退出`。

### 6.7.2 同步原语

| 类 | 关键方法 | 说明 |
|----|---------|------|
| 互斥锁类 | `加锁 (是否仅尝试@假)`、`解锁` | 保证临界区互斥访问，本线程锁可重入 |
| 信号灯类 | `等待 (是否仅尝试@假)`、`限时等待 (毫秒)`、`放行`、`重置`、`取句柄` | 基于信号灯值同步，初始值为0 |
| 同步事件类 | `等待`、`限时等待`、`放行`、`重置`、`取句柄` | 与信号灯类方法形态一致 |
| 读写锁类 | `开始读`、`结束读`、`开始写`、`结束写` | 多读单写场景 |
| 原子类型类 | `取值`、`置值`、`替换值`、`加`、`减`、`按位与/或/异或`、`比较赋值`、`等待值改变`、`是否无锁` | 无锁并发计数/状态，`基本原子类型模板类` 派生 原子整数/长整数/小数/逻辑型类 等9个实现类 |

**线程使用示例**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 工作线程 <类型 = 线程类>

工作线程.启动 ()    // 开始执行"线程运行"事件处理方法，成功返回真

// 主线程等待工作线程结束
工作线程.停止 ()    // 通知并等待"线程运行"事件处理方法执行完毕

方法 工作线程_线程运行 <接收事件>
{
    // 在线程中执行的耗时任务；须频繁检查是否需要退出
    判断循环 (工作线程.是否需要退出 () == 假)
    {
        调试输出 ("线程工作中")
    }
}
```

> **注意事项**："线程运行"事件处理方法在独立线程中运行，须频繁调用 `是否需要退出 ()`，返回真即尽快退出，否则主线程的 `停止 ()` 会死等；线程处理方法中不能直接操作界面组件，需通过"主线程处理器"（`发送通知`/`投递通知` → `接收到通知` 事件在 UI 主线程触发）把任务投递回主线程执行；多线程共享数据时务必加锁或使用原子类型，避免数据竞争。界面线程（主线程）中执行耗时任务会造成界面卡顿，应放子线程（见18.7节）。

## 6.10 本章易错点总结

1. **对象比较**：`==` 比较地址，比较内容用 `对象内容是否相同`；字节集类比较内容用 `字节集内容是否相同`（与 `对象内容是否相同` 等效）；
2. **文本换行**：视窗平台换行用 `"\r\n"` 而非 `"\n"`；
3. **数组索引**：从 0 开始；
4. **线程安全**：跨线程操作界面组件会崩溃，需投递回主线程；
5. **流关闭**：使用完流对象建议 `关闭`（非必需，流对象销毁时自动关闭，关闭会清除流中现有出错状态）；
6. **随机数**：需随机性场景先 `置随机数种子`；
7. **异常**：俘获范围尽量小，配合日志排查。

## 本章小结

- 视窗基本类是全书地基：所有对象派生自 `对象类`，比较对象要分清"引用"与"值"语义；
- **文本类是 Unicode-16 编码**，字符处理、编码转换、与字节集互转都建立在这一前提上；
- 数组、字节集、流是三大数据容器，掌握"创建 → 操作 → 释放（流用完建议 `关闭`，销毁时自动关闭）"闭环即可胜任多数数据处理；
- 异常俘获、多线程（`线程类` + 临界区/事件等同步原语）、内置网络类（`客户`/`服务器`/数据报类）可组合出中小型程序骨架；
- 数值转换与随机数有坑：需要随机性先 `置随机数种子`，注意隐式类型转换边界。
