# 07 第三方扩展模块速查

> 蒸馏自《火山视窗全栈开发技能书》第10章"第三方扩展模块源码解析"与附录B"常用模块速查表"（当前版本 V2.6）。类名/方法名/参数名均来自各模块 `_j.txt` 公开接口文件，遵循"宁可少写不可写错"原则；模块由社区开发者（以"飞翔的企鹅"为代表）封装，官方模块标注"官方"。

## 一、AI 模块（阿里百炼大模型，包 `火山.AI`）

| 类 | 包 | 说明 / 关键成员 |
|----|-----|------|
| `阿里云问答类` | 火山.AI | 问答主类：`提问(欲提问的内容/文本型, 是否清除先前问答记录/逻辑型)`→void；`清除先前问答记录()`→void；`停止回答()`→void；事件 `正在回答(回答结果/阿里云问答结果类)` |
| `阿里云问答结果类` | 火山.AI | 仅属性无方法：`思考内容`/文本型、`回答内容`/文本型、`完成原因`/文本型（如"stop"）、`Token数`/整数、`错误原因`/文本型 |
| `流式网络访问类` | 火山.AI | 底层流式 HTTP 访问类，提供"网页访问"和事件回调 |

- 静态 vs 成员：`阿里云问答类.密钥 = "your-api-key"`（密钥为**静态成员**，须类名访问）；`问答对象.模型 = "deepseek-r1"`（模型为**实例变量**）。
- **密钥安全**：API 密钥不能硬编码发布，可用程序综合库静态方法 `读环境变量_ (用户环境变量@真, 环境变量名称)` → 文本型 动态获取。
- **流式特性**：`正在回答` 事件可能多次触发（每次返回增量文本），需在事件中累积显示。
- **事件命名**：接收方法必须命名为 `阿里云问答类_正在回答`（**类名**+事件名，见17.9），不可用实例变量名前缀（`问答对象_正在回答` 不会触发）；须声明 `来源对象/阿里云问答类`、`标记值/整数`、`回答结果/阿里云问答结果类` 三个参数。
- **网络依赖**：需在具有网络访问权的线程中调用；IDE 输出窗口可查看网络请求日志。
- **上下文字段**：`提问` 第二参为真时清空对话历史；为假时保持上下文（多轮对话）。
- **停止方法**：`停止回答` 用于中途取消，建议窗口关闭或用户取消时调用。

{

    方法 启动方法 <公开 类型 = 整数>
    {

    }

    变量 标签1 <类型 = 标签 隐藏值属性 = "0">

        // 设置 API 密钥与模型（密钥从阿里云百炼控制台获取）
        // 密钥为静态成员，须用类名访问；模型为实例变量
        阿里云问答类.密钥 = "your-api-key"
        问答对象.模型 = "deepseek-r1"  // 默认值

    }

    方法 按钮_被单击 <接收事件>

        }

| `画直线2(起始横坐标/整数, 终点横坐标/整数, 起始纵坐标/整数, 终点纵坐标/整数, 颜色/图像颜色类, 透明分量@假)` | 无返回值 | 画直线（参数序 X1,X2,Y1,Y2） |
| `画文本(设备句柄/变整数, 内容/文本型, 横坐标/整数, 纵坐标/整数, 字体颜色/图像颜色类, 字体描述/文本型, 字体高度@0, 线条宽度@400, 斜体@假, 下划线@假, 透明通道@假)` | 逻辑型 | 绘制文本（首参为设备句柄） |
| `取像素颜色(横坐标/整数, 纵坐标/整数, 透明分量@真)` | 图像颜色类 | 取像素颜色 |
| `置像素颜色(横坐标/整数, 纵坐标/整数, 颜色/图像颜色类, 透明分量@假)` | 无返回值 | 置像素颜色（整数颜色用 `置像素颜色值`） |

- **格式支持**：`创建自图像文件` 的 `图像类型` 必填；非所有格式都支持写入，保存时选合适 `图像格式类型`（如 `图像格式类型.PNG格式`）。
- **插值算法**：`缩放`/`旋转` 默认不带插值；`重定义尺寸2`（旋转用 `旋转2`）第三参常量：`相邻像素`（快但锯齿）、`双三次`/`双三次2`（质量高但慢）、`Lanczos`（高质量缩小）。
- **GIF 处理**：注意帧延迟与循环次数设置。
- **内存占用**：大分辨率图像（4K）处理完毕及时释放或用 `创建自空白图像` 覆盖。

> 绝大多数方法为**静态方法**，以"所操作的本对象"作第一个参数传入；**处理类方法不直接修改源图，结果写入调用方提供的 `增强位图类` 输出参数**（各方法输出参数名不同）。

- **静态调用模式**：静态方法常规用 `增强位图类.方法名(源图, ...)` 调用；因首参为本类对象，也可写成 `源图.方法名(...)`（编译器自动转换），两种写法等价。
- **输出参数模式**：旋转/缩放/二值化/灰度/中值/均值滤波/膨胀/腐蚀/细化/轮廓/马赛克/亮度/反色/椒盐噪声**不修改源图**，须传目标 `增强位图类` 变量作末参（输出参数名各异：结果位图/结果图片/滤波后的图片/旋转后的图片/缩放后的图片/存放位图）。
- **前置条件**：膨胀/腐蚀/细化要求源图黑白；轮廓只能提取字体类位图（如验证码）且必须先二值化；二值化阈值 0-255；亮度 -255~255；马赛克强度从 1 起。
- **无核大小参数**：中值/均值滤波无核大小参数（不同于 OpenCV 风格滤波）。

### 2.3 摄像头与 CV AI（总览）

**摄像头模块（`摄像头操作库`，DirectShow）**：`摄像头类`（打开设备/预览/录制/采样）；`视频播放器`（置父窗口/置窗口尺寸/全屏模式(属性)）；`音视频操作类`（静态：枚举摄像头/枚举麦克风/取设备名称/取设备路径）；`视频采样器`（事件 `得到数据(数据指针/变整数, 数据长度/整数)`）。

```火山代码
变量 摄像头 <类型 = 摄像头类>
变量 采样器 <类型 = 视频采样器>

如果 (摄像头.打开设备 (0))          // 打开第1个摄像头（索引从0开始）
{
    摄像头.启用采样 (采样器, 假)      // 启用采样回调（快照模式=假）
    摄像头.启用预览 (0)              // 父窗口句柄=0（无父窗口，独立预览窗口）
    摄像头.运行 ()                   // 开始采集
}
变量 快照 <类型 = 字节集类>
快照 = 摄像头.采样拍照 ()            // 抓取一帧（返回字节集）
摄像头.停止 ()
摄像头.关闭设备 ()
```

- **调用顺序**：`打开设备` → `启用采样`（须在 `启用预览` 之前）→ `启用预览`/`启用录制`（须在 `运行` 之前）→ `运行`；`采样拍照` 须在 `启用采样`+`运行` 之后。
- **设备枚举**：`音视频操作类.枚举摄像头`/`枚举麦克风` 为嵌入式循环方法，循环内用 `取设备名称`/`取设备路径`。
- **采样事件**：接收方法命名 `视频采样器_得到数据`，加 `<接收事件 类型 = 整数>`，签名为 `(来源对象, 标记值, 数据指针/变整数, 数据长度/整数)`。

### 3.2 Elk JS 引擎（包 `火山.视窗.ELK引擎`）

> 轻量级（几十 KB 级）；JS 功能有限，**不支持 JIT 编译和 C++/JS 双向互操作**。核心类：`ELK引擎类`、`ELK对象类`。

| 方法（ELK引擎类） | 说明 |
|------|------|
| `执行(内容/文本型)` | 执行 JS 代码并以文本返回结果（每次执行后保留上下文变量，可通过 `分配运行内存` 重置） |
| `执行2(内容/字节集类)` | 执行 JS 代码，返回 `ELK对象类` 结果对象（配合 `取对象文本` 转文本） |
| `分配运行内存(所欲分配尺寸/整数)` | 重定义引擎内存（默认256，须≥256）；调用会重置引擎，清空已保存的 JS 上下文 |
| `取全局对象()` / `创建新对象()` | 获取全局 JS 对象 / 创建空 JS 对象（返回 `ELK对象类`） |

| `重置()` | 清除引擎所有状态，相当于重分配内存 |

- **定位**：适合体积敏感、JS 功能简单的场景（配置文件解析、简单表达式计算），不适合作大型脚本引擎。
- **无双向互操作**：不支持从 C++ 注册函数到 JS 中供脚本调用（与 V8 和 Python 不同）。
- **内存限制**：用 `分配运行内存` 限制引擎消耗，防脚本内存泄漏拖垮宿主。

- **版本选择**：OpenSSL 3.x 移除 MD5/DES/RC4/RC2 等过时算法，依赖这些算法不要调用 `使用新版本()`。
- **编译时处理**：`使用新版本()` 是编译时处理，编译器检测到调用即启用对应编译特性，与方法实际是否被执行无关。

- **填充方式**：ECB/CBC 要求数据对齐块大小（16 字节）；零填充最简单，PKCS7 最常用且标准。
- **字节集与文本型**：加解密数据参数为字节集类，与文本型互转注意编码（UTF-8 vs ANSI）。
- **RSA 局限**：1024 位密钥最多加密 117 字节；大文件用 AES + RSA 加密 AES 密钥的混合方案。

## 八、常见易错点汇总（10.8）
### 8.1 通用问题

- **模块引用缺失**：使用模块前必须先在项目属性中引用对应模块（如 `火山.AI`、`火山.视窗.OPENSSL`），否则编译报"未找到类"。
- **包名混淆**：类名相似也可能不同包（`图像处理类` 在 `火山.视窗.图像处理`，`增强位图类` 在 `火山.视窗.增强位图处理`）。
- **静态 vs 成员方法**：全静态模块（增强位图类、加解密类）必须 `类名.方法名(...)`；常规成员方法（CxImage 图像处理类）用 `对象.方法名(...)`。
- **DLL 部署遗漏**：V8 需 ICU + V8 DLL；ECharts 需 MiniBlink DLL；Python 需 python39.dll；OpenSSL 需 libcrypto + libssl DLL。发布用 Dependency Walker 或 IDE 静态编译选项检查。
- **事件挂接**：①方法名命名 `类名_事件名`（如 `按钮_被单击`）；②声明 `<接收事件>`；③控件变量为非静态成员变量。三者缺一不可。
- **编译时 vs 运行时**：OpenSSL `使用新版本`（及 ECharts `使用Edge浏览框`）为编译时处理（通过检测代码中是否调用启用编译特性）；Breakpad `注册` 调用会附加 Release 编译参数（生成 pdb），但注册动作本身必须在运行时执行（Debug 版不生效）。
### 8.2 加解密类易错点

- **密钥长度与密钥位不匹配**：AES 密钥字节数须与密钥位严格对应（16字节=128位、24字节=192位、32字节=256位）。
- **密文编码**：加密输出为原始字节集，传输/文本存储需 Base64（`字节集类.字节集到BASE64文本 (数据, 编码格式@BASE64编码方式.标准, 每行最大字符数@0)` → 文本型；编码格式 `BASE64编码方式.标准`/`URL专用`/`正则专用`）；解密前用 `字节集类.BASE64文本到字节集 (编码文本)` 解码。直接 `到文本(密文)` 会因非 UTF-8 字节乱码或截断。
- **ECB 模式局限**：逐块加密，相同明文块产生相同密文块，不适合作安全敏感场景；优先 CBC（需 IV 向量）。
### 8.3 脚本引擎易错点

- **初始化顺序错误**：V8 的 `平台 -> 隔离空间 -> 环境 -> 脚本` 层级严格有序，跳过中间层直接使用高层对象会导致崩溃；Python 的 `初始化` 必须在所有其他 API 之前。
- **引用计数泄漏（Python）**：`Py列表类.添加成员()` 后元素引用计数 +1，删除列表时不减计数则元素无法释放；长时间运行的 Python 脚本宿主务必做引用计数审计。
- **线程安全**：V8 隔离空间与执行环境不能跨线程共享（isolate 单线程）；多线程需为每线程创建独立隔离空间或使用 V8 Locker 机制。Elk 无此限制，但也不支持多线程并发。
### 8.4 图像处理易错点

- **像素格式**：CxImage 加载后内部像素格式可能不同（24-bit RGB、32-bit ARGB、8-bit 灰度等）；某些操作（如修改透明通道）仅在 32-bit 图像上有效，需先转换格式。
- **GDI 资源泄漏**：CxImage 内部使用 GDI 句柄，循环创建/销毁大量图像对象须保证正常析构，避免 GDI 句柄泄漏导致界面卡死。
### 8.5 ECharts 图表易错点

- **准备就绪时序**：所有图表配置必须在 `准备就绪` 事件之后执行，窗口启动方法中直接操作图表对象会失败。
- **WebView2 依赖**：Windows 7 或精简版 Windows 10 可能未安装 WebView2 Runtime，安装程序需附带 Evergreen Bootstrapper。
- **JS 注入时机**：`执行JS脚本` 应在 `画图()` 之前调用，否则 JS 配置可能被 `画图()` 生成的默认配置覆盖。
### 8.6 PDF 生成易错点

- **坐标系原点**：PDF 的 (0,0) 在左下角，A4 纵向页面高度为 842（单位 1/72 英寸即 point），Y 坐标从底部向上递增，与视窗 GUI 左上角坐标系相反。
- **中文乱码**：内置字体（如 Helvetica）绘制中文显示空白或方框；必须加载含目标字符集的 TTF（如 `simsun.ttc`、`msyh.ttc`），文档文本编码类型为 `PDF文本编码类型.简体中文`（模块默认即此值）。

## 九、本章小结

- 第三方模块各自依赖独立 SDK/运行库（海康、AutoCAD、阿里云、百度网盘等），加入工程前先确认 `dependence` 依赖与目标环境；
- AI（百炼）需配置密钥；脚本引擎（V8/Python）注意初始化时机与资源释放（Python 引用计数）；
- 加密（OpenSSL）注意填充模式（`数据填充模式.PKCS7`）与密钥管理；图像（CxImage/增强位图）注意 GDI 释放；
- 摄像头走"打开设备 → 启用采样 → 采样拍照"流程；渲染类（WebView2/ECharts）注意 Runtime 依赖与 JS 注入时机（`画图()` 之前）。
