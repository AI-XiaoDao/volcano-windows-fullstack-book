# 第一部分 语法类错误排查

## 第17章 常见语法错误排查手册

> 本章汇总 wsv 格式标准与封装语法中的高频错误，并在 17.14 补充 IDE 操作类问题。每个问题按"错误现象 → 原因 → 正确写法"组织。

### 17.0 错误现象快速定位表

> 按你看到的报错现象/关键词，先在下面定位到对应小节，再回看该小节的"原因 → 正确写法"。

| 报错现象（关键词） | 定位小节 | 核心原因一句话 |
|------|------|------|
| "文件格式错误"、文件打不开 | 17.1 | 首行缺 `<火山程序 类型 = "通常" 版本 = 1 />`，或文件非 UTF-8 编码 |
| 名称带空格/括号等特殊字符 | 17.2 | 成员名称非法，需用双引号转义字符串（`变量 "我的 变量"`） |
| 属性值解析异常、`123a` 报错 | 17.3 | 属性表语法错误；非数值/名称格式的值必须用双引号括住 |

| 输出无换行、出现 `\n` 字面量 | 17.5 | 视窗平台换行必须用 `\r\n`；引号/反斜杠转义错误 |

| 嵌入替换为空、参数被引用多次 | 17.10 | 嵌入行 `@<成员名称>` 替换符用法错误，参数仅可引用一次 |
| 嵌入式方法报"非嵌入语句" | 17.11 | 嵌入式方法存在严格使用限制（无返回值、仅嵌入行等） |

### 17.1 文件首行声明缺失或错误

**现象**：打开或编译时提示"文件格式错误"、解析器无法识别。

**原因**：`.wsv` 文件的首非空行必须是文档格式和版本定义行。

**正确写法**：

```wsv
<火山程序 类型 = "通常" 版本 = 1 />
```

- `类型/type` 取值：`通常` / `normal`；
- `版本/version`：目前最新为 1。

> 无论完整程序数据还是剪切程序数据，此声明行都是必需的。
>
> **注意**：本章其余小节（17.2/17.3/17.6/17.7/17.10 等）的"正确写法"围栏均为**剪切程序数据片段**——直接保存为 `.wsv` 文件或复制粘贴时，`<火山程序 类型 = "通常" 版本 = 1 />` 声明行必须作为首非空行；且片段内的顶层变量/方法/语句仅剪切程序数据允许，若作为完整程序文件使用，须按 17.13 置于包/类/方法体内。

### 17.2 成员名称非法

**现象**：成员名称带空格、括号等特殊字符时报错，或 IDE 提示输入"名称"无效。

**原因**：成员名称如果不为有效的单/全名称文本，必须使用双引号括住的转义字符串格式。

**正确写法**：

```wsv
变量 "我的 变量" <类型 = 整数>
```

**单名称规则**：以英文字母/下划线/汉字开头，后跟字母/下划线/数字/汉字。**名称对大小写敏感**，`abc` 与 `ABC` 不是同一名称。

### 17.3 属性表语法错误

**现象**：属性表内容解析异常、属性值类型不对、`@` 引导的属性名无法识别。

**原因与正确写法**：

- 属性表用尖括号括住：`<属性名称 [= 属性值] ...>`；

- 属性名称如非有效单/全名称（可 `@` 引导）或与系统属性重名，必须用双引号转义；

- 系统属性值可为名称文本、逻辑值（真/假）、数值（123、1.23、0x123、-123、1.23e3）或双引号字符串；无法用这些格式时必须用双引号括住（如 `"123a"`）；

- 未提供属性值时默认为逻辑值真；

- "值"属性或非系统属性还可提供数组 `{ 1, 2, 3 }`、以 `@` 开头的本地名称引用、`@"..."` 本地文本等。

```火山代码
变量 变量2 <类型 = 文本型 值 = "123a">
```

> **易错点**：属性值 `123a` 必须以 `"123a"` 描述，否则解析器把它当作数值 123 后跟非法字符 `a`。

### 17.4 语句行必须以空属性表开头的情况

**现象**：语句行以 `<` 开头、或内容首单词是 `包/类/方法/参数/常量/变量` 等保留字、或内容是单个 `{` / `}` 时，报语法错误。

**原因**：这些情况解析器需要借助空属性表 `<>` 区分"语句行"与"成员定义行"。

**正确写法**：

```火山代码
<> 包 ...
<> 类 ...
<> 变量 ...
<> { ... }
<> <...
```

同理，注释/嵌入行内容以 `<` 开头时也必须加空属性表：`# <> <abc`。

> **易错点**：流程语句（如果/否则/判断循环/循环等）的 `{` 与 `}` 必须**独占一行**，不能单行书写（如 `如果 (x) { ... }` 是错误的，官方样例全部换行书写）；`如果` 必须带子语句体（不能直接接"否则"）；`否则` 必须紧跟"如果"语句体的 `}` 之后，且省略判断条件后不能再后续跟随其它"否则"。

### 17.5 字符串转义与换行错误

**现象**：运行输出中文本没有换行、出现反斜杠字面量、或编译报非法转义。

**原因与正确写法**：

| 意图 | 错误写法 | 正确写法 |
|------|---------|---------|
| 换行 | `"\n"` | `"\r\n"`（视窗平台需回车+换行两个字符） |
| 双引号 | `"a"b"` | `"a\"b"` |
| 反斜杠 | `"C:\dir"` | `"C:\\dir"` |
| 制表符 | 直接用 Tab | `"\t"` |
| Unicode | - | `"\uXXXX"`（后跟 1-4 个十六进制字符） |

**视窗平台注意**：在火山视窗平台里，欲达到换行效果必须插入 `\r\n`。

### 17.6 数组定义与使用错误

**现象**：多维数组维数不匹配、数组成员访问越界、数组初始值格式错误。

**原因与正确写法**：

- 数组类型：基本/类数据类型后跟数组维定义，如 `文本 []`、`整数 [] []`、`整数 [3][3]`；

- 数组立即数用花括号：`{ 1, 2, 3 }`，多维可嵌套；

- **多维数组各维成员数目必须相等**，`{ { 1, 2 }, { 3 } }` 不允许（仅可在提供数组常量/变量初始值时使用嵌套）。

```火山代码
变量 整数数组 <类型 = 整数 [] 值 = { 1, 2, 3 }>
```

### 17.7 常量初始值错误

**现象**：为常量成员赋非立即数值时报错。

**原因**：常量初始值只能提供**立即数**，不能提供其它常量。

**正确写法**：

```火山代码
常量 常量1 <公开 类型 = 整数 值 = 123>
```

如需引用本地 C++ 名称值，可用 `@` 引导：`常量 相邻像素 <公开 值 = @"@CxImage::InterpolationMethod::IM_NEAREST_NEIGHBOUR">`（火山编译器不检查其有效性，用户自行保证）。

### 17.8 参考变量与实例变量混淆

**现象**：对象变量未创建实例就访问成员报"空对象"；或把两个变量误当作同一对象。

**原因**：变量 `参考` 属性为假时自动创建实例对象；为真时仅作为指向其它已有实例的引用。

**正确写法**：

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

变量 实例对象 <类型 = 我的类 注释 = "自动创建实例">
变量 引用对象 <类型 = 我的类 参考 = 真 注释 = "仅作引用，需先赋值为已有对象">
引用对象 = 实例对象
```

### 17.9 事件方法命名与挂接错误

**现象**：事件收不到、事件接收方法不触发。

**原因与正确写法**：

- **自动挂接**：非静态的类成员变量若其数据类型为类且定义了事件，会自动挂接到当前类；静态成员变量不支持自动挂接事件；

- **手动挂接**：`挂接事件 (对象, 标记值)` 手动挂接对象事件（官方 demo 中用于数据库等对象），标记值传给接收方法的 `标记值` 参数；动态创建的窗口/组件同样用本命令挂接后其事件才能被接收；

- **取消挂接**：手动 `挂接事件` 挂接的对象用关键字 `取消事件挂接 (对象)` 取消（自动挂接与手动挂接的对象均可取消）；若使用视窗基本类的通用事件机制（`事件发送器`），则用对应实例的 `事件发送器对象.取消挂接 ()` 方法；接收器/组件对象被销毁后事件连接自动断开；

- **事件接收方法命名格式**：`类名 + "_" + 事件名`（如 `按钮_被单击`、`时钟_周期事件`），并声明 `<接收事件>`。

```火山代码
<火山程序 类型 = "通常" 版本 = 1 />

方法 按钮_被单击 <接收事件>
参数 来源对象 <类型 = 按钮>
参数 标记值 <类型 = 整数>
{
    // 处理按钮单击事件
}
```

> **易错点**：方法名与 `类名_事件名` 不匹配、或漏写 `<接收事件>` 属性，事件不会触发。

### 17.10 嵌入行与替换符错误

**现象**：嵌入行中 `@<成员名称>` 替换为空、编译报错、参数被引用多次报错。

**原因与正确写法**：

- 嵌入行替换符：`@<成员名称>`、`@n<成员名称>`、`@dt<类型名称>`、`@pkg<包名称>`、`@an<约定名称>` 等；

- **注意：所有参数仅允许在嵌入行中引用一次**（需求类型为"数据类型"的参数除外）；

- 选项字符：`n` 用纯粹名称、`e` 未找到时整行删除不报错、`b` 找到/未找到替换为真/假文本；

- 特殊名称 `@sn<current_class>`、`@sn<startup_method>` 等可引用运行期上下文名称。

```火山代码
@ 返回 @<对象变量1.成员1>
```

### 17.11 嵌入式方法使用限制

**现象**：嵌入式方法定义了返回值、或包含了非嵌入语句时编译报错。

**原因**：嵌入式方法有严格限制：

1. 自动禁止流程检查；

2. 设置有 `has_body` / `has_loop_body` / `prev` / `next` 时不能定义返回值；

3. 类_初始化 / 类_清理 / 属性写 / 事件定义 / 事件接收 / 虚拟方法均不能设置为嵌入式方法；

4. 嵌入式方法内只能存在嵌入行语句；

5. 嵌入行内访问参数以外成员时必须明确指定类名前缀，且该类必须为公开类。

### 17.12 包定义错误

**现象**：多个包定义、包定义不在文件首部、包名非法。

**原因与正确写法**：

- 包定义**必须位于源文件首部且只能存在一个**；

- 多个程序文件可具有相同包名，此时内容视为处于同一个包中；

- 包名必须为全名称（多个单名称以句点组合），如 `包 火山.视窗.网络`；

- 包支持 `@外部包` 属性（允许多设置项），指定源文件内优先查询的外部包名列表，解决类名冲突。

### 17.13 类定义位置错误

**现象**：类定义出现在方法体内部、或类嵌套类报错。

**原因**：类必须位于**文档顶层**；方法、参数、常量、变量有各自的归属位置：

| 成员 | 必须位置 |
|------|---------|
| 类 | 文档顶层 |
| 方法 | 类定义体中（剪切程序数据中可位于文档顶层） |
| 参数 | 方法定义行后面 |
| 类成员常量/变量 | 类定义体中 |
| 局部常量/变量 | 方法子语句体中 |

### 17.14 IDE 操作类常见问题

**现象**：代码看着没错，但 IDE 层面出问题——找不到类、文件打不开、编译配置不对。

**原因与处理**：

| 问题 | 处理 |
|------|------|
| 打开 `.wsv` 报"文件格式错误" | 首非空行必须是 `<火山程序 类型 = "通常" 版本 = 1 />`；文件须为 UTF-8 编码（用记事本另存为 UTF-8） |
| 引用某个类报"未找到类" | ① 该类所属模块是否已加入工程（15.10）；② 模块 `dependence` 依赖是否齐全；③ 类名大小写；④ 该类是否公开类 |
| 加入模块后 IDE 工程树未刷新 | 重新打开解决方案或右键刷新；确认 `.vprj` 的模块 `child_filter` 已包含对应 `.vgrp` |
| 编译输出与预期不符（EXE/DLL 混了） | 检查 `settings.project.result_type`（1=DLL/2=EXE） |
| 高分辨率下 IDE 界面模糊 | 系统设置中开启"程序DPI缩放"（工程 `auto_support_high_dpi` 只影响编译产物的高 DPI 行为，不能解决 IDE 自身界面模糊） |
| 工程文件（`.vprj`/`.vsln`）损坏无法打开 | 用纯文本编辑器打开检查 `num_child_filters`/`num_files` 计数与实际是否一致；损坏前建议用文本方式备份 |
| 调试 DLL 项目按 F5 无反应 | 配置 `debug_command_line`（指定调用该 DLL 的宿主 EXE） |
| 输出目录残留旧产物干扰判断 | 清理 `..\out\` 目录后重新编译 |

> **通用原则**：火山工程文件（`.vprj`/`.vsln`/`.vgrp`）都是 UTF-8 纯文本，**任何 IDE 异常都可以用文本编辑器打开工程文件人工核查**——这是排查 IDE 层问题的最后手段。

### 18.0 运行现象快速定位表

| 数据库连接失败 | 18.6 | 连接串、驱动、服务可达性、权限、SQLite 路径 |

| 编译慢/内存泄漏/卡顿 | 18.11 | 减模块、按需编译、循环创建对象未释放、转储分析 |

### 18.1 启动即崩溃或闪退

**现象**：双击 EXE 一闪而过，或启动时崩溃。

**排查思路**：

1. **控制台程序先验证**：将启动方法先改为控制台输出，确认程序能进入主逻辑；

2. **检查启动类**：启动方法是否位于名为"启动类"的类中，且基础类配置正确；

3. **查看崩溃日志**：使用"程序崩溃自动处理"（breakpad）模块，在代码中（如窗口"创建完毕"事件里）调用静态方法 `程序崩溃处理类.注册` 挂接静态回调方法，收集 minidump；

4. **隔离测试**：逐段注释业务代码，定位崩溃点。

**breakpad 接入示意**（真实接口：在窗口 `创建完毕` 中调用 `程序崩溃处理类.注册`，回调须为静态方法）：

```火山代码
类 我的主窗口 <基础类 = 窗口>
{
    方法 我的主窗口_创建完毕 <接收事件 类型 = 整数>
    参数 来源对象 <类型 = 我的主窗口>
    参数 标记值 <类型 = 整数>
    {
        // 处理类型默认"所有",可省略;仅Release版生效
        程序崩溃处理类.注册 (取运行目录 (), 异常回调函数)
        返回 (0)
    }

    方法 异常回调函数 <静态 类型 = 逻辑型>
    参数 文件路径 <类型 = 文本型>
    参数 ID <类型 = 文本型>
    参数 写出成功 <类型 = 逻辑型>
    {
        返回 (真)
    }
}
```

> 注：完整示例（含回调内写出提示、越界触发崩溃验证 dump 生成）见技能书 10.7.1「wsv 源码示例」。

### 18.2 运行时缺少 DLL

**现象**：运行时提示"找不到 xxx.dll"。

**原因**：

- 模块声明的 `@视窗.附属文件` 未随 EXE 分发；

- 使用了动态链接运行库但目标机器缺少；

- DLL 位数（32/64）与 EXE 不一致。

**处理**：发布时检查附属文件清单；必要时开启 `static_runtime_lib = true` 静态链接；核对位数匹配。

### 18.3 模块引用后编译报"找不到类/方法"

**现象**：加入了模块，但代码中引用其类/方法时编译报错。

**排查思路**：

1. **确认模块已加入工程**：检查 `.vprj` 的 child_filter 是否包含对应 `.vgrp`；

2. **核对模块依赖**：该模块的 `dependence` 依赖模块是否也已加入；

3. **核对包名**：类是否通过正确的包引用（`@外部包` 未配置时优先查询的包名是否正确）；

4. **核对大小写**：火山名称大小写敏感；

5. **核对公开状态**：非公开类只能在所处包内访问。

### 18.4 界面在高 DPI 下模糊

**现象**：高分屏（如 2K/4K）上界面文字、控件模糊。

**处理**：在 `.vprj` 设置 `settings.project.auto_support_high_dpi = true`，重新编译。

### 18.5 网络模块请求失败

**现象**：HTTP 请求超时、连接被拒、返回空。

**排查思路**：

1. **URL 与端口**：确认协议（http/https）、端口、路径正确；

2. **代理/防火墙**：企业环境需走系统代理的请求确认模块是否支持代理设置；

3. **证书**：HTTPS 请求在目标机器缺证书或日期错误时失败，检查系统时间与证书链；

4. **超时与重试**：设置合理的超时时间，业务层做重试；

5. **日志**：打开模块的调试输出或网络库的日志，查看握手与状态码。

### 18.6 数据库连接失败

**现象**：ADO/MySQL/SQLite 连接报错或查询失败。

**排查思路**：

1. **连接串**：核对服务器地址、端口、库名、账号密码；

2. **驱动**：ADO 需系统具备对应 OLE DB 驱动；MySQL 客户端模块需 `dependence` 的库完整；

3. **服务状态**：确认数据库服务在本机/远程可达（`ping`、`telnet` 端口）；

4. **权限**：账号对目标库表是否有增删改查权限；

5. **SQLite 文件路径**：确认数据库文件路径可写、不存在目录权限问题。

### 18.7 线程与界面卡顿

**现象**：界面无响应、数据量大时卡死。

**处理**：

- **耗时操作放子线程**：使用"视窗基本类"模块的多线程支持（`线程类`/`全局线程池` 等）处理耗时任务；

- **线程安全**：多线程环境下跨线程访问界面组件需通过消息投递/回调切回主线程，直接操作可能崩溃；

- **避免死锁**：小心同步原语的加锁顺序；`@视窗.前缀文本` 嵌入的 C++ 同步代码更需谨慎。

### 18.8 日志排查技巧

**现象**：问题偶发、难以复现。

**处理**：引入"日志记录库"（Plog）模块，在关键路径输出分级日志（debug/info/warning/error），发布后通过日志定位问题：

```火山代码
// 初始化(静态):接收级别"调试",预设_文件格式,日志文件路径,单文件上限100KB,最多5个滚动文件
日志类.初始化文件 (日志级别.调试, 日志格式预设_文件, "log\\app.log", 102400, 5)

// 分级输出(静态)
日志输出.信息 ("启动应用")
日志输出.警告 ("关键路径耗时：" + 到文本 (耗时))
日志输出.错误 ("操作失败：" + 错误信息)
```

> 注：`日志类.初始化文件` 与 `日志输出.信息/警告/错误` 均为**静态**调用；完整签名、`日志格式预设_*` 与 `日志输出模式` 见技能书 10.7.2。

### 18.9 异常与错误处理兜底

**现象**：未处理异常导致程序崩溃。

**处理**：

- 使用"程序崩溃自动处理"（breakpad）模块在崩溃时生成转储文件并上报；

- 对外部返回的关键调用做空对象/返回值判断，避免连锁空引用；

- 数据操作、网络、文件等 I/O 类操作加入失败分支与重试策略。

### 18.10 构建与部署问题

**现象**：编译通过、本机运行正常，但换机器/换配置就出问题。

**排查思路**：

| 现象 | 原因 | 处理 |
|------|------|------|
| 目标机器提示"找不到 DLL" | 模块的 `@视窗.附属文件` 未随 EXE 分发 | 按 16.3 打包清单核对附属文件 |
| 32/64 位混用加载失败 | 附属 DLL 位数与 EXE 不一致 | 统一 `target_platform`；`$(p)` 输出目录区分 win32/x64 |
| 运行库缺失 | 动态链接运行库，目标机器无 VC 运行库 | `static_runtime_lib = true` 静态链接 |
| 调试版正常、发布版异常 | `为调试版()` 分支、未初始化变量、优化行为差异 | 用发布版复现；检查条件编译分支 |
| 输出目录找不到产物 | `out_file_name` 用了 `$(p)`/`$(r)` 等变量 | 按 `..\out\$(p)\文件名` 定位，或固定绝对输出路径 |
| 预定义宏不生效 | 宏名/作用范围写错（大小写、逗号分隔） | 核对模块接口中的宏名（如 `_VOL_CURL_VER2`） |

### 18.11 IDE 性能与资源排查

**现象**：IDE 卡顿、程序运行缓慢、内存只增不减。

**排查思路**：

1. **大工程卡顿**：把不常用模块从工程中移除（模块 `.vgrp` 一旦加入，其全部源文件进入编译范围，模块越多编译越慢）；用"按需编译"特性——只写会被执行到的代码，未执行代码不参与编译；

2. **内存只增不减**：重点排查循环中反复声明的局部类对象变量未释放（wsv 中 `变量 <类型 = 类名>` 声明即按"参考=假"自动创建实例，局部变量离开作用域时自动销毁，勿套用 C++ 的 `new`/`delete` 思路）、Python 引用计数未 `减少引用计数`（见 10.3.3）、图像处理大量 `创建自图像文件` 未释放 GDI（见 10.2.1）；

3. **界面卡顿**：耗时操作放子线程（见 18.7）；大量 `调试输出` 在发布版/高频循环中会拖慢运行，用 `为调试版()` 包起来；

4. **编译缓慢**：首次编译 VS 工具链冷启动较慢属正常；频繁全量编译可考虑减少模块、拆分工程；

5. **崩溃转储分析**：breakpad 生成的 `.dmp` + 同版本 `.pdb` + `.exe` 拖入 VS 即可定位崩溃栈（见 10.7.1）。
