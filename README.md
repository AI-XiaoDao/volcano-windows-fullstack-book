# 火山视窗（Volcano Windows）全栈开发技能书

火山视窗 PC 平台（wsv 文本格式源程序）全栈开发资料包：基于火山官方导出的原始知识库（1,290 个文件）经 60 轮校验（含多代理对抗式复核）产出的最终成品。

## 使用 Skill 包

将 `.claude/skills/volcano-windows-dev/` 复制到你的项目或用户级 `.claude/skills/` 目录即可。该 Skill 提供火山视窗开发的三条红线、标准开发流程与分主题速查：

1. **禁止编造 API**：每个类/方法/属性/事件/常量必须有知识库接口文件（`*_j.txt`）原文证据；
2. **代码必须完全符合 wsv 格式标准**（声明行/成员定义/属性表/`<>` 前缀/逻辑值/注释标记）；
3. **证据优先级**：`火山wsv文件格式标准` ＞ `封装语法手册` ＞ 模块接口 `*_j.txt` ＞ 官方 demo 源码。

> 知识库接口文件 `*_j.txt` 为 UTF-8 编码但多数存在"键名前缀污染"（行首夹带乱码/重复片段），提取时以 `"class name"`/`"method name"` 等 JSON 键值本身为准（详见 Skill 包 `references/09-知识库使用指引.md`）。

- 主书/手册/术语表/校验报告为基于知识库的整理产物，校验依据逐条可追溯（见《执行校验报告》60 节）；实际安装模块存在版本差异时，以 IDE 中类声明为准。
