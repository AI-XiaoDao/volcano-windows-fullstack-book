## 使用 Skill 包

将 `.claude/skills/volcano-windows-dev/` 复制到你的项目或用户级 `.claude/skills/` 目录即可。该 Skill 提供火山视窗开发的三条红线、标准开发流程与分主题速查：

1. **禁止编造 API**：每个类/方法/属性/事件/常量必须有知识库接口文件（`*_j.txt`）原文证据；
2. **代码必须完全符合 wsv 格式标准**（声明行/成员定义/属性表/`<>` 前缀/逻辑值/注释标记）；
3. **证据优先级**：`火山wsv文件格式标准` ＞ `封装语法手册` ＞ 模块接口 `*_j.txt` ＞ 官方 demo 源码。

> Skill 包中的知识库路径指火山官方 AI 知识库（封装语法手册/模块信息/项目文件格式规范/389 对模块接口与源码/254 对官方示例），需另行获取；接口文件 `*_p.txt` 为双重编码，解码配方见 `references/09-知识库使用指引.md`。

## 说明

- 所有内容以知识库原文为依据，代码示例符合《火山wsv文件格式标准》；实际安装模块存在版本差异时，以 IDE 中类声明为准；
- 主书/手册/术语表/校验报告为原创整理产物，校验依据逐条可追溯（见《执行校验报告》60 节）。
