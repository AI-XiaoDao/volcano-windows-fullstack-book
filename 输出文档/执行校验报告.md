## 七、wsv 注释语法系统性修正（2026-08-13 第四轮）

**问题**：全书代码围栏内存在 298 处以 `'` 引导的注释（注释行 247 处 + 行尾注释 51 处）。经核实，`'` 在 wsv 中**并非注释标记**，而是字符字面量定界符：

| 依据 | 结论 |
|------|------|
| 《火山wsv文件格式标准》§2 表 | 文档/类注释/嵌入行用 `#`；语句注释用 `//`（标准示例 `参数1.信息框 ("abc") // 注释信息`）；`'` 仅用于字符值（`'a'`、`' '`） |
| 视窗wsv源码demo知识库（12 个真实 Demo 解码后） | `//` 注释 91 处，`'` 行注释 **0 处** |
| 本书第 1.7 节自身文档 | 语句注释为 `//` 引导 |

**修正**：代码围栏内将 `'` 注释统一替换为 `//`（注释行 `' xxx` → `// xxx`；行尾 `… ' xxx` → `… // xxx`）。替换前先保护字符字面量（`' '` 等）避免误伤。

**校验结果**：
- 296 处替换，全部位于代码围栏内；正文/表格等围栏外内容 **0 处改动**；
- 行数 7893 不变，代码围栏 258（偶数）配对正常；
- 修复后围栏内仅剩 2 处单引号，均为合法字符字面量（`' '`）；
- 修复前原文件已备份为 `火山视窗全栈开发技能书.md.bak-单引号注释修复`；
- 已同步确认《常见问题排查手册》与本书第 1.7 节、附录A语法速查卡中的注释语法描述均为 `//`，与新代码一致。

> 本次修正使全部可直接抄入 IDE 的代码示例的注释语法与 wsv 标准/真实源码一致，消除"复制代码到 IDE 报语法错误"的隐患。
